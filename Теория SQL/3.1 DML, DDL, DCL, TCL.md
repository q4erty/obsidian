В SQL существует несколько основных типов команд, каждая из которых выполняет свою функцию. Эти команды можно разделить на четыре категории: DML, DDL, DCL и TCL. Давайте рассмотрим каждую категорию подробнее.

**DML (Data Manipulation Language)**

DML включает в себя команды, предназначенные для манипуляции данными внутри таблиц базы данных. К основным командам DML относятся:

- SELECT – выборка данных из одной или нескольких таблиц.

- INSERT – вставка новых записей в таблицу.

- UPDATE – обновление существующих записей в таблице.

- DELETE – удаление записей из таблицы.

**DDL (Data Definition Language)**

DDL содержит команды, которые используются для создания, изменения и удаления объектов базы данных, таких как таблицы, индексы, представления и другие структуры. Основные команды DDL включают:

- CREATE – создание нового объекта базы данных.

- ALTER – изменение существующего объекта базы данных.

- DROP – удаление объекта базы данных.

- TRUNCATE – очистка содержимого таблицы без возможности отката изменений.

**DCL (Data Control Language)**

DCL отвечает за управление доступом к данным и объектам базы данных. С помощью этих команд администраторы могут предоставлять и отзывать права доступа пользователям. Основные команды DCL:

- GRANT – предоставление прав доступа пользователю или роли.

- REVOKE – отзыв ранее предоставленных прав доступа.

**TCL (Transaction Control Language)**

TCL включает в себя команды, используемые для управления транзакциями в базе данных. Транзакции позволяют выполнять набор операций как единое целое, обеспечивая целостность данных. Основные команды TCL:

- COMMIT – фиксация всех изменений, выполненных в рамках текущей транзакции.

- ROLLBACK – отмена всех изменений, выполненных в рамках текущей транзакции.

- SAVEPOINT – установка точки сохранения внутри транзакции, до которой можно вернуться при необходимости.
