Slowly Changing Dimensions (SCD) - это правила, по которым мы поддерживаем историчность изменения атрибутов в таблицах.  
Мы рассмотрим три основных типа SCD: тип 1, тип 2 и тип 3 на примерах - так будет понятнее.  
Примером будет служить изменение номера паспорта клиента с  123-4567 на 789-4321. Дата изменения паспорта - 2025-01-05.

| client_id | name | passport |
| --------- | ---- | -------- |
| 101       | Petr | 123-4567 |

---

## **SCD Тип 1**

SCD тип 1 предполагает перезапись старых данных новыми. Этот метод подходит для ситуаций, когда история изменений не важна, и текущие данные всегда актуальны.

Пример **SCD Тип 1** после изменения номера паспорта**:**

| client_id | name | passport |
| --------- | ---- | -------- |
| 101       | Petr | 789-4321 |

---

## **SCD Тип 2 (наиболее часто встречающийся в хранилищах данных)**

SCD тип 2 сохраняет историю изменений, создавая новые записи для каждого изменения. Это позволяет отслеживать все изменения, происходящие с измерениями.

Пример **SCD Тип 2** после изменения номера паспорта**:**

| client_id | name | passport | valid_from | valid_to   | is_valid |
| --------- | ---- | -------- | ---------- | ---------- | -------- |
| 101       | Petr | 123-4567 | 2024-01-01 | 2025-01-04 | 0        |
| 101       | Petr | 789-4321 | 2025-01-05 | 9999-12-31 | 1        |

---

## **SCD Тип 3**

SCD тип 3 сохраняет последние два (и более) состояния измерения в одной записи. Это достигается путем добавления дополнительных колонок для хранения старого значения атрибута.

| client_id | name | passport | prev_passport |
| --------- | ---- | -------- | ------------- |
| 101       | Petr | 789-4321 | 123-4567      |



Проще говоря, SCD 1 - перезаписываем значение, SCD 2 - создаем новую строку с новым значением, SCD 3 - создаем колонку с новым значением.
