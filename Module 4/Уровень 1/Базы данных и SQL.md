## 1. Введение и немного истории

История хранения данных прошла долгий путь от медленной последовательной обработки на перфокартах и магнитных лентах до появления дисковых накопителей с иерархическими и сетевыми моделями баз данных. Ключевым моментом стали 1970-е годы, когда Эдгар Кодд предложил **реляционную модель**, которая сегодня является стандартом де-факто. Позже, с развитием интернета и необходимостью хранить колоссальные объемы информации, появились базы данных **NoSQL**, ориентированные на гибкость и масштабируемость.

## 2. Базы данных и СУБД

В физическом смысле база данных (БД) — это папка на диске, а таблицы внутри нее — это отдельные файлы. Каждая таблица состоит из строк и колонок , причем у каждой колонки есть строго заданное имя и тип данных (все ячейки в одной колонке хранят значения одинакового типа).

Для работы с БД используется **СУБД (Система Управления Базами Данных)**. Она:

- Предоставляет интерфейс для операций **CRUD** (создание, чтение, обновление, удаление).
    
- Обеспечивает целостность и безопасность данных.
    

**Популярные СУБД делятся на два лагеря:**

- **Реляционные:** MySQL, PostgreSQL (самые популярные классические решения), а также мощные платные корпоративные системы Oracle и MS SQL Server.
    
- **NoSQL:** MongoDB (документно-ориентированная), Redis (быстрый кеш), Cassandra (для огромных объемов) и Neo4j (для графовых данных).
    

_Примечание к курсу:_ Практика в лекциях построена на базе MySQL (версия 8.0) с использованием учебной базы данных **Sakila**, которая моделирует систему проката DVD-дисков (актеры, фильмы, клиенты, платежи).

## 3. Язык SQL

**SQL (Structured Query Language)** — стандартизированный язык для работы с реляционными БД. Наиболее широко поддерживаемый стандарт — SQL-92, который описывает JOIN-операции, транзакции, блокировки и временные таблицы.

**Особенности синтаксиса:**

- Запросы нечувствительны к регистру, но по общепринятому соглашению ключевые слова (`SELECT`, `FROM` и т.д.) пишутся заглавными буквами.
    
- Переносы строк не учитываются — СУБД воспринимает запрос как одну длинную строку.
    
- Комментарии в коде обозначаются двумя дефисами `--`.
    

**Интересный факт:** Изначально язык был разработан IBM в 1970-х и назывался SEQUEL, но из-за проблем с торговой маркой его сократили до SQL (убрав гласные). Поэтому до сих пор его произносят двояко: "Эс-Кью-Эль" (чаще в Европе) или "Сиквел" (в США).

## 4. Основы построения запросов (SELECT)

Базовый запрос состоит из команд `SELECT` (что выбрать), `FROM` (откуда) и `WHERE` (по какому условию).

### Фильтрация и логические операторы

Для создания сложных условий в `WHERE` используются логические операторы:

- **AND:** Требует выполнения обоих условий.
    
- **OR:** Требует выполнения хотя бы одного из условий.
    
- **NOT:** Инвертирует (отрицает) результат условия.
    
- _Порядок выполнения:_ `NOT` -> `AND` -> `OR`. Для изменения порядка нужно использовать круглые скобки.
    

### Специальные операторы

- **BETWEEN:** Задает диапазон значений. Границы диапазона **включаются** в результат. Применимо к числам, датам и строкам.
    
- **IN:** Заменяет цепочку условий `OR`, позволяя проверить, совпадает ли значение с одним из вариантов в заданном списке (пишется в круглых скобках).
    
- **LIKE / NOT LIKE:** Поиск по шаблону строк.
    
    - Символ `%` заменяет любую последовательность символов (или пустую строку).
        
    - Символ `_` заменяет строго один любой символ.
        

### Работа с результатом

- **LIMIT и OFFSET:** Используются для постраничного вывода. `LIMIT` ограничивает максимальное количество возвращаемых строк, а `OFFSET` указывает, сколько строк с начала нужно пропустить.
    
- **DISTINCT:** Убирает дубликаты из результата. Важно: уникальность проверяется сразу по всем колонкам, перечисленным в `SELECT`.
    
- **ORDER BY:** Сортирует результат. По умолчанию по возрастанию (`ASC`), для убывания используется модификатор `DESC`. Можно сортировать сразу по нескольким колонкам.
    

## 5. Значение NULL

**NULL** — это специальное маркерное значение, означающее "данные отсутствуют", "неизвестно" или "неприменимо".

- Это не ноль и не пустая строка, это именно "ничто".
    
- Обычные операторы сравнения (`=`, `>`, `<`) с `NULL` всегда возвращают логическое состояние `UNKNOWN` (не `true` и не `false`). Строка попадает в результат `WHERE` только если условие возвращает строго `true`.
    
- Для правильной проверки на `NULL` существуют специальные операторы: **`IS NULL`** и **`IS NOT NULL`**.
