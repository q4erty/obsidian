## 1. Декартово произведение (Cartesian Product)

Самый простой, но опасный способ получить данные из нескольких таблиц — перечислить их через запятую в блоке `FROM`.

- **Как это работает:** Каждая строка первой таблицы соединяется с каждой строкой второй таблицы.
    
- **Результат:** Если в таблице А 10 строк, а в таблице Б 20 строк, на выходе будет **10 * 20 = 200 строк**.
    
    В реальных базах это почти никогда не нужно, так как создает огромный объем избыточных данных.
    

## 2. Объединение таблиц (JOIN)

Чтобы объединить таблицы осмысленно (по ключам), используются операторы `JOIN`. Это основной инструмент реляционных баз данных.

### Основные типы JOIN:

- **INNER JOIN (Внутреннее объединение):** Возвращает только те строки, для которых нашлось совпадение в обеих таблицах. Если записи в одной из таблиц нет пары, она не попадет в результат.
    
- **LEFT JOIN (Левое внешнее объединение):** Возвращает **все** строки из левой таблицы и подходящие строки из правой. Если в правой таблице совпадений нет, вместо данных будут подставлены `NULL`.
    
- **RIGHT JOIN (Правое внешнее объединение):** Работает зеркально `LEFT JOIN` — приоритет отдается правой таблице. На практике используется редко, так как любой `RIGHT JOIN` можно переписать в `LEFT JOIN`, просто поменяв таблицы местами.
    
- **CROSS JOIN:** Явное указание декартова произведения (редко используется в бизнес-логике).
    

**Синтаксис:**

SQL

```
SELECT t1.column, t2.column
FROM table1 t1
JOIN table2 t2 ON t1.id = t2.t1_id; -- условие связи
```

## 3. Псевдонимы (Aliases)

Когда вы работаете с несколькими таблицами, имена колонок могут совпадать (например, `id`). Чтобы СУБД понимала, о какой колонке речь, используются псевдонимы таблиц:

- `FROM sakila.actor AS a` или просто `FROM sakila.actor a`.
    
- Это делает запрос короче и читабельнее.
    

## 4. Подзапросы (Subqueries)

Подзапрос — это запрос `SELECT`, вложенный внутрь другого SQL-запроса.

- **Где они используются:** В блоках `SELECT`, `FROM` или `WHERE`.
    
- **Операторы для подзапросов:** `IN`, `NOT IN`, `ANY`, `ALL`, `EXISTS`.
    
- **Пример:** Найти актеров, которые снимались в фильмах с определенным рейтингом. Мы сначала ищем ID нужных фильмов во вложенном запросе, а потом передаем этот список во внешний запрос.
    

## 5. Оператор WITH (CTE)

**Common Table Expression (Обобщенное табличное выражение)** — это способ создать временную именованную таблицу прямо внутри основного запроса.

- **Зачем это нужно:**
    
    1. Повышает читаемость сложных запросов.
        
    2. Позволяет использовать один и тот же подзапрос несколько раз, не дублируя код.
        
    3. Удобно для вычисления промежуточных данных (например, средних значений), которые потом нужно сравнить с каждой строкой основной таблицы.
        

**Пример структуры:**

SQL

```
WITH temp_table AS (
    SELECT category_id, AVG(price) as avg_price 
    FROM products GROUP BY category_id
)
SELECT p.name, p.price 
FROM products p 
JOIN temp_table tt ON p.category_id = tt.category_id
WHERE p.price > tt.avg_price; -- товары дороже среднего по категории
```

## 6. Объединение результатов (UNION)

Если `JOIN` склеивает таблицы "в ширину" (добавляет колонки), то `UNION` склеивает их "в высоту" (добавляет строки).

- **UNION:** Объединяет два запроса и удаляет дубликаты.
    
- **UNION ALL:** Объединяет запросы и оставляет все строки, включая повторяющиеся (работает быстрее, так как не тратит ресурсы на поиск дублей).
    
- **Условие:** Количество и типы данных колонок в обоих `SELECT` должны полностью совпадать.
