## 1. Основные типы данных

Все данные в SQL разделены на категории. Правильный выбор типа данных критически важен для производительности и экономии места на диске.

### Числовые типы

- **Целые числа (Integers):**
    
    - `TINYINT` (1 байт): от -128 до 127.
        
    - `SMALLINT` (2 байта): до ~32 тысяч.
        
    - `INT` / `INTEGER` (4 байта): до ~2 миллиардов (самый частый выбор).
        
    - `BIGINT` (8 байт): для огромных чисел (например, ID в больших соцсетях).
        
- **Числа с плавающей точкой:**
    
    - `FLOAT` и `DOUBLE`: для научных расчетов (могут иметь погрешности округления).
        
    - `DECIMAL(M, D)`: для финансовых данных. Обеспечивает максимальную точность. `M` — общее количество цифр, `D` — цифры после запятой.
        

### Строковые типы

- **`CHAR(n)`:** Строка фиксированной длины. Если записать меньше символов, остальное забьется пробелами. Работает быстро.
    
- **`VARCHAR(n)`:** Строка переменной длины. Занимает ровно столько места, сколько символов в строке (+1-2 байта на длину).
    
- **`TEXT` / `BLOB`:** Для хранения больших текстов или бинарных данных (картинки, файлы).
    

### Дата и время

- **`DATE`:** Только дата (ГГГГ-ММ-ДД).
    
- **`TIME`:** Только время.
    
- **`DATETIME`:** Дата и время.
    
- **`TIMESTAMP`:** Хранит количество секунд с 1970 года. Удобен тем, что автоматически конвертируется под часовой пояс сервера/клиента.

## 2. Строковые функции

Используются для манипуляции текстом прямо в запросе.

- `CONCAT(str1, str2)` — склеивает строки.
    
- `LOWER(str)` / `UPPER(str)` — меняет регистр.
    
- `LENGTH(str)` — возвращает длину строки в байтах.
    
- `CHAR_LENGTH(str)` — возвращает количество символов (важно для кириллицы).
    
- `SUBSTRING(str, start, len)` — вырезает кусок текста.
    
- `REPLACE(str, from, to)` — заменяет часть строки.
    
- `TRIM(str)` — удаляет лишние пробелы по краям.
    

---

## 3. Числовые функции

- `ABS(x)` — модуль числа.
    
- `ROUND(x, d)` — округление до `d` знаков после запятой.
    
- `CEILING(x)` — округление до ближайшего целого **вверх**.
    
- `FLOOR(x)` — округление до ближайшего целого **вниз**.
    
- `RAND()` — генерация случайного числа от 0 до 1.
    

---

## 4. Функции даты и времени

Позволяют вычислять возраст, стаж или фильтровать события за период.

- `NOW()` — текущая дата и время.
    
- `CURDATE()` — только сегодняшняя дата.
    
- `DATE_ADD(date, INTERVAL 1 DAY)` — прибавить время к дате.
    
- `DATEDIFF(date1, date2)` — разница между датами в днях.
    
- `YEAR()`, `MONTH()`, `DAY()`, `HOUR()` — извлечение части даты.
    

---

## 5. Приведение типов (Casting)

Иногда нужно принудительно изменить тип данных в запросе, например, превратить число в строку для склейки.

**Синтаксис:**

SQL

```
SELECT CAST(payment_date AS DATE) FROM sakila.payment;
-- Или в стиле MySQL:
SELECT CONVERT(amount, CHAR) FROM sakila.payment;
```

## Практический совет:

Выбирая между `DATETIME` и `TIMESTAMP`, помните: `TIMESTAMP` занимает меньше места (4 байта против 8) и умеет работать с часовыми поясами, но его диапазон ограничен 2038 годом. Для исторических данных (даты рождения) лучше использовать `DATE` или `DATETIME`.
