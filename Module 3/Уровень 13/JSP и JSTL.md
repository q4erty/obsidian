## 1. В чем была проблема? (Зачем придумали JSP)

В прошлой лекции мы изучали Сервлеты. Чтобы вернуть пользователю веб-страницу через Сервлет, нам приходилось писать HTML-код прямо внутри строк Java:

Java

```
// Это Сервлет. Писать HTML внутри Java — это боль.
out.println("<html>");
out.println("<head><title>Моя страница</title></head>");
out.println("<body><h1>Привет, " + user.getName() + "!</h1></body>");
out.println("</html>");
```

Это **ужасно неудобно**. Если страница большая, код превращается в нечитаемую кашу. Верстальщик (frontend-разработчик) вообще не сможет работать с таким файлом, ведь он не знает Java.

**Решение — JSP (JavaServer Pages).**

Это технология, которая позволяет сделать наоборот: **писать куски Java-кода прямо внутри обычного HTML-файла**.

Java

```
<html>
<body>
    <h1>Привет, <%= user.getName() %>!</h1>
</body>
</html>
```

---

## 2. Как JSP работает "под капотом"? (Важный секрет)

Сервер (Tomcat) не умеет выполнять HTML-страницы. Он понимает только Сервлеты (Java-классы).

Поэтому, когда пользователь впервые запрашивает вашу JSP-страничку, происходит магия:

1. Tomcat берет ваш `.jsp` файл.
    
2. **Превращает его в настоящий Java-Сервлет** (генерирует `.java` файл, где весь ваш HTML заботливо обернут в `out.println()`).
    
3. Компилирует его в `.class`.
    
4. Запускает как обычный Сервлет!
    

> **Вывод:** JSP — это просто удобный "шаблон", который Tomcat сам за кулисами превращает в Сервлет.

---

## 3. Синтаксис JSP (Как вставлять Java в HTML)

Чтобы сервер понял, где обычный HTML, а где начинается Java, используются специальные скобки:

### А. Скриптлеты: `<% код %>`

Внутри этих скобок можно писать любой стандартный Java-код (создавать переменные, писать циклы `for` и условия `if`).

Java

```
<% 
   int a = 5;
   int b = 10;
   int sum = a + b;
%>
```

### Б. Выражения (Expressions): `<%= переменная %>`

Используется, чтобы **вывести** значение переменной прямо на веб-страницу (аналог `out.print()`). Обрати внимание: тут есть знак `=`, но в конце _нет точки с запятой_.

Java

```
<p>Сумма равна: <%= sum %></p>
```

### В. Директивы: `<%@ ... %>`

Это инструкции для самого сервера (Tomcat). Например, если в вашем Java-коде внутри JSP нужно использовать класс `ArrayList`, его нужно импортировать:

Java

```
<%@ page import="java.util.ArrayList" %>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
```

## 4. Новая проблема: "Спагетти-код"

Разработчики обрадовались JSP и стали писать всю логику (походы в базу данных, сложные циклы) прямо внутри HTML.

Получился **"спагетти-код"** — HTML и Java переплелись так, что читать это стало невозможно.

Java

```
<% for(User u : userList) { %>
    <% if(u.getAge() > 18) { %>
        <p>Взрослый: <%= u.getName() %></p>
    <% } %>
<% } %>
```

Опять же, frontend-разработчик смотрит на эти скобки `<% } %>` и сходит с ума.

## 5. Эволюция и решение: JSTL и EL

Чтобы очистить HTML-страницы от уродливого Java-кода, придумали два новых инструмента.

### Инструмент 1: EL (Expression Language)

Это язык выражений. Он позволяет обращаться к переменным очень коротко и красиво, используя синтаксис `${...}`.

- **Было (JSP):** `<%= request.getAttribute("user").getName() %>`
    
- **Стало (EL):** `${user.name}`
    

### Инструмент 2: JSTL (JSP Standard Tag Library)

Это стандартная библиотека тегов. Разработчики решили: "А давайте заменим Java-циклы и Java-условия на специальные HTML-теги!".

Для использования JSTL нужно подключить эту библиотеку в проект (через Maven) и добавить директиву на страницу.

**Главные теги JSTL (Core):**

- `<c:if>` — заменяет Java-условие `if`.
    
- `<c:forEach>` — заменяет Java-цикл `for`.
    
- `<c:out>` — безопасный вывод текста на экран.
    

**Как преобразился код благодаря JSTL + EL:**

Java

```
<c:forEach var="u" items="${userList}">
    
    <c:if test="${u.age > 18}">
        <p>Взрослый: <c:out value="${u.name}"/></p>
    </c:if>

</c:forEach>
```

Теперь код выглядит как обычный HTML/XML. Верстальщику с ним работать очень легко!

## Итог (Краткая выжимка)

1. **Сервлеты** — это Java-код, в который неудобно писать HTML.
    
2. **JSP** — это HTML-код, в который можно вставлять Java-код. Tomcat сам превращает JSP в Сервлет при запуске.
    
3. Писать чистую Java внутри JSP (скриптлеты `<% %>`) — **устаревшая и плохая практика** (спагетти-код).
    
4. Вместо этого используют **EL** (`${переменная}`) для вывода данных и **JSTL** (`<c:forEach>`, `<c:if>`) для логики. В современном JSP-файле вообще не должно быть строчек кода на чистой Java.
