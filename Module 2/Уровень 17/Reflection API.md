## 1. Что такое Рефлексия?

Обычно мы пишем код, зная имена классов и методов заранее. Рефлексия позволяет работать с кодом, имена классов, полей и методов которого мы узнаем только **во время запуска** программы (Runtime).

**Возможности:**

1. Узнать структуру любого класса (какие есть поля, методы, кто родитель).
    
2. Создать объект класса, зная только его текстовое имя.
    
3. Вызвать метод по имени (строке).
    
4. **Взломать инкапсуляцию:** получить доступ к `private` полям и методам.


---

## 2. Точка входа: Класс `Class`

Вся работа начинается с получения специального объекта типа `Class`. Это "паспорт" любого объекта или типа в Java.

**3 способа получить объект `Class`:**

1. **У объекта:** `Class c = myObject.getClass();`
    
2. **У типа:** `Class c = String.class;`
    
3. **По имени (строка):** `Class c = Class.forName("java.lang.String");` (именно так работают плагины и драйверы БД).


---

## 3. Работа с содержимым класса

Получив объект `Class`, мы можем достать из него "запчасти" (метаданные).

### Основные классы пакета `java.lang.reflect`:

- **`Field`**: Описывает переменную класса (имя, тип, значение).
    
- **`Method`**: Описывает метод (имя, параметры, возвращаемый тип).
    
- **`Constructor`**: Описывает конструктор.


### Разница методов `get...` и `getDeclared...`

При получении списка полей или методов есть важное различие:

- `getFields()` / `getMethods()` — возвращает только **public** элементы (включая унаследованные от родителей).
    
- `getDeclaredFields()` / `getDeclaredMethods()` — возвращает **ВСЕ** элементы (private, protected, public), но **только** объявленные в этом конкретном классе (без родительских).

## 4. Создание объектов и вызов методов

Рефлексия позволяет создавать объекты без оператора `new` и вызывать методы без точки.

### Создание экземпляра

``` java
Class<?> clazz = Class.forName("MyClass");
// Вызов пустого конструктора (устаревший метод, но часто встречается в лекциях)
Object obj = clazz.newInstance(); 

// Правильный современный способ (через конструктор)
Constructor<?> constructor = clazz.getConstructor(String.class);
Object obj = constructor.newInstance("Argument");
```

### Вызов метода

``` java
Method m = clazz.getMethod("doSomething", int.class);
// Вызываем метод m у объекта obj с аргументом 5
m.invoke(obj, 5); 
```

## 5. Взлом инкапсуляции (Private Fields)

Это самая частая причина использования рефлексии в фреймворках (Spring, Hibernate, GSON). Вы можете читать и менять даже `private` и `final` поля.

**Алгоритм:**

1. Получить поле через `getDeclaredField("name")`.
    
2. **Отключить проверку доступа:** `field.setAccessible(true)`.
    
3. Прочитать или изменить значение.


**Пример:**

``` java
Cat cat = new Cat("Tom"); // Внутри есть private String name;

Field field = cat.getClass().getDeclaredField("name");
field.setAccessible(true); // "Взламываем" доступ
field.set(cat, "Jerry");   // Теперь кота зовут Jerry
// Хороший тон — вернуть доступ обратно, если это возможно, но не обязательно
```

## 6. Dynamic Proxy (Динамический Прокси)

Это продвинутая часть лекции. Java позволяет создавать классы "на лету", реализующие определенные интерфейсы.

**Зачем это нужно?**

Чтобы перехватывать вызовы методов. Например, вы хотите, чтобы перед каждым вызовом метода писался лог в консоль, но не хотите менять код самого класса.

**Как это работает:**

1. Есть интерфейс (например, `Reader`).
    
2. Вы создаете `Proxy`, который реализует этот интерфейс.
    
3. Вся логика прописывается в специальном обработчике — **`InvocationHandler`**.


**Метод `invoke`:**

У `InvocationHandler` есть один метод, в который попадают **все** вызовы методов прокси-объекта.

``` java
// Пример логики "перехватчика"
public Object invoke(Object proxy, Method method, Object[] args) {
    System.out.println("Вызван метод: " + method.getName());
    // Тут можно решить: выполнить реальный метод или сделать что-то другое
    return method.invoke(originalObject, args);
}
```

**Где применяется:**

- Spring (аннотации `@Transactional`, `@Autowired`).
    
- Hibernate (ленивая загрузка данных из БД).
    
- Mock-тестирование (Mockito).
