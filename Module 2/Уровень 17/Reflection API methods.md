### 1. Получение объекта типа `Class` (Точка входа)

Чтобы начать работать с рефлексией, нужно получить ссылку на класс.

- `.getClass()` — вызов на экземпляре объекта (например, `cat.getClass()`).
    
- `.class` — обращение через литерал типа (например, `String.class`, `int.class`).
    
- `Class.forName("имя.класса")` — загрузка класса по его полному строковому имени (например, `"java.lang.String"`).


### 2. Создание объектов (Инстанцирование)

- `.newInstance()` — создание объекта (вызов конструктора без параметров). _В лекции отмечено как устаревший, но базовый способ._
    
- `.getConstructor(Class<?>... parameterTypes)` — получение конкретного конструктора.
    
- `.newInstance(Object... initargs)` — создание объекта через полученный конструктор с передачей аргументов.


### 3. Работа с полями (Field)

Методы класса `Class` для поиска полей:

- `.getFields()` — возвращает массив всех **public** полей (включая родительские).
    
- `.getDeclaredFields()` — возвращает массив **всех** полей (private, protected, public), но только объявленных в этом классе.
    
- `.getField("имя")` — получение конкретного публичного поля по имени.
    
- `.getDeclaredField("имя")` — получение конкретного (даже приватного) поля по имени.


Методы класса `Field` (для работы с самим полем):

- `.setAccessible(true)` — **ключевая команда** для отключения проверки прав доступа (позволяет менять private поля).
    
- `.set(Object obj, Object value)` — устанавливает новое значение поля для конкретного объекта.
    
- `.get(Object obj)` — получает текущее значение поля у объекта.
    
- `.getType()` — возвращает тип данных этого поля.


### 4. Работа с методами (Method)

Методы класса `Class` для поиска методов:

- `.getMethods()` — массив всех public методов.
    
- `.getMethod("имя", Class<?>... parameterTypes)` — получение конкретного метода по имени и типам аргументов.


Методы класса `Method` (для вызова):

- `.invoke(Object obj, Object... args)` — вызывает этот метод у объекта `obj` с аргументами `args`.
    
- `.getName()` — возвращает имя метода.
    
- `.getReturnType()` — возвращает тип возвращаемого значения.


### 5. Получение информации о структуре

- `.getSuperclass()` — получить родительский класс.
    
- `.getInterfaces()` — получить список интерфейсов, которые реализует класс.
    
- `.getModifiers()` — получить модификаторы (public, static, final и т.д.) в виде числа.


### 6. Dynamic Proxy (Динамический прокси)

Классы и методы для создания прокси-объектов:

- `java.lang.reflect.Proxy` — основной класс.
    
- `Proxy.newProxyInstance(ClassLoader, Interfaces[], InvocationHandler)` — создание экземпляра прокси.
    
- `InvocationHandler` — интерфейс перехватчика.
    
- `invoke(Object proxy, Method method, Object[] args)` — метод внутри `InvocationHandler`, который перехватывает все вызовы.


### Сводный пример из лекции (взлом private поля):

``` java
// 1. Получаем класс
Class<?> clazz = cat.getClass(); 

// 2. Получаем скрытое поле
Field field = clazz.getDeclaredField("name"); 

// 3. Разрешаем доступ
field.setAccessible(true); 

// 4. Меняем значение
field.set(cat, "Jerry"); 

// 5. Возвращаем защиту (хороший тон)
field.setAccessible(false);
```
