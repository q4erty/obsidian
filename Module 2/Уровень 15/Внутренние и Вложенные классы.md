## 1. Внутренние классы (Inner Classes)

Это простые нестатические классы, объявленные внутри другого класса.

### Главная особенность

Объект внутреннего класса **всегда связан** с конкретным объектом внешнего класса.

- Он содержит скрытую ссылку на экземпляр внешнего класса.
    
- Он имеет доступ ко **всем** полям и методам внешнего класса (даже `private`).


### Ограничения

1. **Статический контекст:** Нельзя создать объект внутреннего класса внутри статического метода (например, `main`) без предварительного создания объекта внешнего класса.
    
2. **Статика внутри:** Внутренний класс (в классических версиях Java) не может содержать статические поля и методы (кроме констант `static final`).


### Синтаксис создания

Выглядит необычно, так как мы создаем объект "через" другой объект:

``` java
OuterClass outer = new OuterClass();
// Создаем inner, используя ссылку на outer
OuterClass.InnerClass inner = outer.new InnerClass();
```

## 2. Вложенные статические классы (Static Nested Classes)

Это классы, объявленные внутри другого с ключевым словом **`static`**.

### Главная особенность

По сути, это обычный класс, который просто «спрятан» внутри другого для порядка.

- Он **не хранит** ссылку на объект внешнего класса.
    
- Он **не имеет** доступа к нестатическим полям внешнего класса (так как не привязан к конкретному объекту).
    
- Имеет доступ только к `private static` переменным родителя.


### Синтаксис создания

Создается как обычный объект, просто имя класса указывается через точку:

``` java
// Объект внешнего класса НЕ нужен
OuterClass.StaticNested nested = new OuterClass.StaticNested();
```

---

## 3. Сравнение: Inner vs Static Nested

Это самый частый вопрос на собеседовании по этой теме.

| **Характеристика**  | **Внутренний (Inner)**                     | **Вложенный статический (Static Nested)**                         |
| ------------------- | ------------------------------------------ | ----------------------------------------------------------------- |
| **Ключевое слово**  | Без `static`                               | `static`                                                          |
| **Связь с внешним** | Жестко связан с объектом                   | Не связан с объектом                                              |
| **Доступ к полям**  | Видит всё (и static, и instance)           | Видит только static поля внешнего класса                          |
| **Создание**        | `obj.new Inner()`                          | `new Outer.Nested()`                                              |
| **Аналогия**        | Как рука человека (часть конкретного тела) | Как наушники (идут в комплекте с телефоном, но работают отдельно) |

## 4. Анонимные классы (Anonymous Classes)

Это особый вид внутренних классов, которые объявляются и создаются **одновременно** в месте использования. У них нет своего имени.

- **Зачем нужны:** Когда вам нужно создать объект, переопределить всего один метод (например, для обработки клика кнопки или запуска потока) и вы не хотите создавать для этого отдельный файл класса.
    
- **Что происходит:** Компилятор создает скрытый класс-наследник и сразу делает `new`.


### Пример (Создание потока)

Обычный способ (долго):

``` java
class MyRun implements Runnable { ... }
Runnable r = new MyRun();
```

Анонимный класс (быстро):

``` java
// Мы как бы говорим: "Создай объект класса, который реализует Runnable,
// и вот тебе реализация метода run прямо здесь"
Thread thread = new Thread(new Runnable() {
    public void run() {
        System.out.println("Работа внутри анонимного класса");
    }
});
```

## 5. Примеры из JDK (Стандартной библиотеки)

В презентации приведены классические примеры использования этих механизмов в самой Java:

1. **Внутренний класс (Inner):** `AbstractList.Itr`.
    
    - Реализует итератор. Ему нужно иметь доступ к конкретному списку, чтобы бегать по его элементам, поэтому он нестатический.
    
2. **Вложенный статический (Static Nested):** `Integer.IntegerCache`.
    
    - Кэш для чисел (от -128 до 127). Ему не нужно знать о каком-то конкретном объекте `Integer`, он общий для всего класса, поэтому он `static`.
    
3. **Анонимный класс:** Часто используется в потоках ввода-вывода (например, `InputStream`) или при обработке событий в интерфейсах.
