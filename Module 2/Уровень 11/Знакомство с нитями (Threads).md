## 1. Что такое нити (потоки)?

Нити (Threads) используются, когда независимым частям программы нужно выполнять работу параллельно с другими частями.

- **Как это работает на процессоре:** Даже если у компьютера всего одно ядро, процессор создает иллюзию параллельности. Он очень быстро переключается между нитями: выполняет несколько команд одной нити, затем переключается на другую, потом на третью и т.д. .

---

## 2. Создание и запуск нитей

В Java есть два основных способа создать новый поток выполнения.

### Способ 1: Наследование от класса `Thread`

Подходит, если вам нужно создать простой поток и не требуется наследоваться от других классов.

1. Создать свой класс, который наследуется от `Thread`.
    
2. Переопределить в нем метод `run()` — именно в нем пишется код, который должен выполняться параллельно.
    
3. Создать объект этого класса.
    
4. Вызвать метод `start()`.

``` java
class MyThread extends Thread {
    public void run() {
        System.out.println("Привет из побочной нити!");
    }
}
// Запуск:
MyThread thread = new MyThread();
thread.start();
```

### Способ 2: Реализация интерфейса `Runnable`

Это более гибкий и предпочтительный способ, так как в Java нельзя наследоваться от нескольких классов, но можно реализовывать сколько угодно интерфейсов.

1. Создать класс, который реализует интерфейс `Runnable`.
    
2. Реализовать метод `run()`.
    
3. Создать объект этого класса.
    
4. Создать объект класса `Thread`, передав ему в конструктор ваш объект `Runnable`.
    
5. Вызвать метод `start()` у объекта `Thread`.

``` java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Привет из Runnable!");
    }
}
// Запуск:
Thread thread = new Thread(new MyRunnable());
thread.start();
```

### Важное отличие `start()` от `run()`

- Если вызовете **`start()`**: Java создаст новый поток и вызовет в нем метод `run`. Код будет выполняться параллельно.
    
- Если вызовете **`run()`** (напрямую): Метод просто выполнится в текущем потоке (как обычный метод), никакой параллельности не будет.

## 3. Жизненный цикл программы

- Когда вы запускаете программу, начинает работать **Главная нить** (Main thread), которая выполняет метод `main`.
    
- Если главная нить порождает дочерние нити, они начинают жить своей жизнью.
    
- **Правило завершения:** Программа на Java завершается только тогда, когда завершат работу **все** её нити (и главная, и дочерние) . Даже если `main` уже закончился, программа будет висеть, пока работают остальные потоки.

---

## 4. Метод `sleep()` — Пауза

Статический метод `Thread.sleep()` позволяет приостановить выполнение текущей нити.

- **Синтаксис:** `Thread.sleep(миллисекунды)` .
    
- **Особенность:** Метод статический, он всегда усыпляет **текущую** нить (ту, в которой был вызван). Нельзя из одной нити принудительно усыпить другую.
    
- **Исключение:** Метод выбрасывает `InterruptedException`, которое обязательно нужно обрабатывать (try-catch) .

## 5. Остановка потока (Interrupt)

Раньше в Java были методы `stop()`, `suspend()`, `resume()`, но сейчас они **deprecated** (устарели), так как могут привести к нестабильности программы и блокировкам .

### Правильный способ остановки

Единственный надежный способ остановить поток — попросить его остановиться, используя флаг.

1. **Специальная переменная:** В классе `Thread` есть скрытая переменная `isInterrupted`.
    
2. **Метод `interrupt()`:** Когда вы вызываете `thread.interrupt()` из другого потока, вы устанавливаете этот флаг в `true` . Это сигнал потоку: "Пора закругляться".
    
3. **Проверка:** Сам поток должен периодически проверять `Thread.currentThread().isInterrupted()`. Если метод вернул `true`, поток должен корректно завершить работу (выйти из цикла/метода `run`) .

### Взаимодействие `interrupt()` и `sleep()`

Здесь есть важный нюанс. Если поток спит (находится в методе `sleep`), он не может проверить флаг `isInterrupted`.

- Если вызвать `interrupt()` у спящей нити, метод `sleep` выбросит исключение `InterruptedException` .
    
- **Важно:** При выбросе исключения флаг `isInterrupted` **сбрасывается** (становится `false`).
    
- **Решение:** В блоке `catch` нужно снова вызвать `interrupt()`, чтобы восстановить статус прерывания, иначе сигнал об остановке будет потерян.

**Пример правильной остановки:**
``` java
public void run() {
    Thread current = Thread.currentThread();
    while (!current.isInterrupted()) { // Проверяем флаг
        try {
            Thread.sleep(1000); // Работаем или спим
        } catch (InterruptedException e) {
            // Если нас разбудили во время сна сигналом interrupt
            current.interrupt(); // Восстанавливаем флаг, так как sleep его сбросил
        }
    }
}
```
