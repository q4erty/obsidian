# Порядок инициализации и конструкторы

## 1. Загрузка классов (Class Loading)

Перед тем как создать объект, Java-машина (JVM) должна узнать, что это за класс.

- **Ленивая загрузка:** JVM не загружает все классы сразу. Загрузка происходит только тогда, когда к классу происходит первое обращение (создание экземпляра или обращение к статическому полю/методу) .
    
- **Что происходит при загрузке?**
    
    1. Инициализируются **статические переменные** (поля класса).
        
    2. Выполняются **статические блоки инициализации** (`static { ... }`).
    

> **Важно:** Статическая инициализация происходит **только один раз** за всё время работы программы — при первой встрече с классом.

---

## 2. Блоки инициализации

В Java есть специальные блоки кода, которые выглядят как просто фигурные скобки `{}` внутри класса.

### А. Статический блок (`static { ... }`)

- **Синтаксис:** `static { // код }`
    
- **Когда запускается:** При загрузке класса (см. пункт 1).
    
- **Зачем нужен:** Обычно используется для сложной инициализации статических переменных (например, заполнить статический `Map` значениями).


### Б. Нестатический блок (Instance Initialization Block)

- **Синтаксис:** Просто `{ // код }` внутри класса (без `static`).
    
- **Когда запускается:** Каждый раз **при создании нового объекта**.
    
- **Порядок:** Выполняется **до** кода конструктора, но **после** вызова конструктора родителя (super).
    
- **Как это работает:** Компилятор буквально копирует код из этого блока в начало каждого конструктора класса.
    
- **Зачем нужен:** Если у вас несколько конструкторов, и во всех нужно выполнять один и тот же код (чтобы не дублировать его).


---

## 3. Алгоритм создания объекта (Полный цикл)

Когда вы пишете `new ChildClass()`, процессы запускаются в строгом порядке. В презентации указаны основные шаги , ниже они расписаны с необходимыми техническими дополнениями:

### Шаг 1: Подготовка (если класс еще не загружен)

1. Выделяется память под все переменные (поля класса).
    
2. Выполняются **статические блоки** и инициализация **статических полей** (в порядке их написания в коде). _Сначала у родителя, потом у наследника._


### Шаг 2: Инициализация объекта (Instance)

3. **Вызов конструктора:** Мы заходим в конструктор.
    
4. **Вызов родителя:** Первой строкой любого конструктора (явно или неявно) идет вызов `super()`. Мы "поднимаемся" по цепочке наследования до самого верха (до класса `Object`).
    
5. **Инициализация переменных:**
    
    - Когда `super()` отработал и мы вернулись на уровень текущего класса, происходит присваивание значений переменным экземпляра (например, `int x = 10;`).
        
    - Срабатывают **нестатические блоки инициализации** `{ ... }`.
    
6. **Тело конструктора:** И только в самом конце выполняется код, который вы написали внутри конструктора.


---

## 4. Сводная таблица порядка выполнения

Для лучшего запоминания представьте иерархию `Родитель -> Наследник`. Мы создаем `new Наследник()`.

|**Порядок**|**Действие**|**Чей код?**|**Примечание**|
|---|---|---|---|
|**1**|Статические поля и `static {}`|**Родитель**|Один раз|
|**2**|Статические поля и `static {}`|**Наследник**|Один раз|
|**3**|Нестатические поля и блоки `{}`|**Родитель**|При каждом `new`|
|**4**|Конструктор (Constructor body)|**Родитель**||
|**5**|Нестатические поля и блоки `{}`|**Наследник**|При каждом `new`|
|**6**|Конструктор (Constructor body)|**Наследник**||

---

## 5. Особенности конструкторов

- Если вы не написали ни одного конструктора в классе, компилятор создаст **конструктор по умолчанию** (без аргументов) автоматически.
    
- Если вы написали хотя бы один конструктор (даже с аргументами), дефолтный конструктор **не** создается. Если он нужен — пишите его вручную.


## Пример кода для закрепления

``` java
class Parent {
    static { System.out.println("1. Static Parent"); }
    { System.out.println("3. Instance Block Parent"); }
    
    Parent() {
        System.out.println("4. Constructor Parent");
    }
}

class Child extends Parent {
    static { System.out.println("2. Static Child"); }
    { System.out.println("5. Instance Block Child"); }
    
    Child() {
        System.out.println("6. Constructor Child");
    }
}

// При запуске new Child():
// Вывод будет строго по номерам 1 -> 6
```
