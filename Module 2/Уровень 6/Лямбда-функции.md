## 1. Введение: Зачем нужны лямбда-выражения?

До Java 8 для передачи поведения (например, способа сортировки) приходилось создавать анонимные классы, что делало код громоздким. Лямбды — это способ записать анонимную функцию короче и понятнее.

### Эволюция кода (на примере сортировки строк)

В презентации показан переход от старого стиля к новому на примере `Comparator`:

1. **Старый способ (Анонимный класс):**
    
    Мы создаем объект интерфейса `Comparator` и переопределяем метод `compare`.
    
``` java
// Громоздко
Comparator<String> comparator = new Comparator<String>() {
    public int compare(String obj1, String obj2) {
        return obj1.length() - obj2.length();
    }
};
Collections.sort(list, comparator);
```

2. **Лямбда-выражение (Полная запись):**
    
    Убираем "лишний мусор" (название интерфейса, метода), оставляем только аргументы и логику.
    
``` java
Comparator<String> comparator = (String obj1, String obj2) -> {
    return obj1.length() - obj2.length();
};
```

3. **Сокращенная запись (Оптимизация):**
    
    - Типы данных (`String`) можно опустить — компилятор их вычислит сам.
        
    - Если действие в одну строчку, можно убрать `return` и фигурные скобки `{}`.
    
``` java
// Максимально кратко
Collections.sort(list, (s1, s2) -> s1.length() - s2.length());
```


> **Дополнение (Важно знать):** Лямбда-выражения работают только с **Функциональными интерфейсами** — это интерфейсы, у которых есть ровно один абстрактный метод (например, `Comparator`, `Runnable`, `ActionListener`).

---

## 2. Синтаксис Лямбда-выражений

Общая формула: `(параметры) -> { тело функции }`

- **Без параметров:** `() -> System.out.println("Hello")`
    
- **Один параметр:** скобки можно опустить: `x -> x * x`
    
- **Несколько параметров:** `(x, y) -> x + y`
    
- **Многострочный код:** обязательно нужны `{}` и явный `return`.

## 3. Ссылки на методы (Method References)

Это еще более короткая запись лямбды, когда ваше выражение просто вызывает уже существующий метод. Используется оператор `::`.

**Виды ссылок (из презентации):**

1. **Статический метод:** `ClassName::staticMethod`
    
    - _Лямбда:_ `x -> Math.abs(x)`
        
    - _Reference:_ `Math::abs`
    
2. **Метод конкретного объекта:** `object::instanceMethod`
    
    - _Пример:_ `System.out::println` (вместо `x -> System.out.println(x)`)
    
3. **Метод произвольного объекта конкретного типа:** `ClassName::instanceMethod`
    
    - _Пример:_ `String::length` (вместо `s -> s.length()`)
    
4. **Конструктор:** `ClassName::new`
    
    - Используется для создания новых объектов (например, в Stream API).

## 4. Stream API (Потоки данных)

Это мощный инструмент для работы с коллекциями в функциональном стиле.

- **Суть:** Вы не пишете циклы `for` или `while`. Вы строите "конвейер" (pipeline) обработки данных.
    
- **Важно:** Стримы **ленивые** (lazy). Они не начнут выполняться, пока вы не вызовете "терминальную" операцию (например, собрать в список или посчитать количество).


### Этапы работы со стримом:

1. **Источник (Source):** Откуда берем данные (`collection.stream()`, `Arrays.stream()`, `Stream.of()`).
    
2. **Промежуточные операции (Intermediate):** Преобразования (можно делать сколько угодно).
    
3. **Терминальная операция (Terminal):** Конец стрима, запуск выполнения (только одна).


### Основные методы (из слайдов + объяснения):

#### Промежуточные (возвращают новый Stream):

- `filter(Predicate)`: Отфильтровать элементы по условию.
    
    - _Пример:_ Оставить только четные числа.
        
- `map(Function)`: Преобразовать каждый элемент во что-то другое.
    
    - _Пример:_ Превратить список чисел в список строк (`x -> String.valueOf(x)`).
        
- `sorted()`: Сортировка (естественная или с компаратором).
    
- `distinct()`: Убрать дубликаты.
    
- `limit(n)`: Взять только первые `n` элементов.
    
- `skip(n)`: Пропустить первые `n` элементов.
    
- `peek(Consumer)`: Выполнить действие без изменения потока (часто для отладки/лога).
    
- `flatMap()`: "Сплющить" структуру. Если у вас был список списков, `flatMap` сделает один плоский список всех элементов.


#### Терминальные (возвращают результат, закрывают стрим):

- `collect()`: Собрать результат в коллекцию.
    
    - `Collectors.toList()`, `toSet()`, `toMap()`.
        
    - `groupingBy()`: Группировка элементов (как `GROUP BY` в SQL).
        
    - `joining()`: Объединить строки в одну.
        
- `count()`: Вернуть количество элементов.
    
- `anyMatch()`, `allMatch()`, `noneMatch()`: Проверка условий (возвращают `boolean`).
    
- `findFirst()`, `findAny()`: Найти элемент (возвращает `Optional`).
    
- `min()`, `max()`: Найти минимум/максимум.
    
- `forEach()`: Пройтись по всем элементам (например, вывести в консоль).

## 5. Класс Optional

В презентации упоминается `Optional`. Это класс-обертка ("контейнер"), который помогает избежать ошибки `NullPointerException`. В нем может быть значение, а может быть пусто.

**Зачем нужен?**

Методы вроде `min()` или `findFirst()` могут ничего не найти (если список пуст). Вместо того чтобы возвращать `null` (что опасно), они возвращают `Optional`.

**Основные методы Optional:**

- `Optional.of(value)`: Создать (если уверены, что не null).
    
- `Optional.ofNullable(value)`: Создать (безопасно, даже если null).
    
- `isPresent()`: Есть ли значение? (true/false).
    
- `isEmpty()`: Пусто ли? (Java 11+).
    
- `get()`: Достать значение. **Опасно!** Если там пусто, вылетит ошибка `NoSuchElementException`.
    
- **Безопасные способы получить значение:**
    
    - `orElse(default)`: Дай значение, а если пусто — верни `default`.
        
    - `orElseThrow()`: Если пусто — брось ошибку (но явно).

## Пример использования (Сборка всего вместе)

Допустим, у нас есть список имен, и мы хотим:

1. Выбрать имена на букву "А".
    
2. Преобразовать их в верхний регистр.
    
3. Отсортировать.
    
4. Собрать в новый список.


``` java
List<String> names = Arrays.asList("Анна", "Иван", "Алексей", "Борис");

List<String> result = names.stream()        // 1. Создаем стрим
    .filter(s -> s.startsWith("А"))         // 2. Фильтр (Лямбда)
    .map(String::toUpperCase)               // 3. Преобразование (Method Reference)
    .sorted()                               // 4. Сортировка
    .collect(Collectors.toList());          // 5. Терминальная операция
```
