#### 1. Что такое массив?

**Массив** — это контейнер, который хранит множество значений **одного типа**.

- Представь его как многоквартирный дом: адрес у дома один (имя массива), но в нем много квартир, и у каждой есть свой номер (**индекс**).
    
- **Важно:** Размер массива нельзя изменить после создания. Если купили «полку» на 10 мест, 11-е туда уже не впихнуть.


#### 2. Создание массива

Чтобы создать массив, нужно два шага (или один комбинированный):

1. **Объявление:** `int[] numbers;` (мы говорим: «тут будет массив целых чисел»).
    
2. **Создание (выделение памяти):** `numbers = new int[5];` (теперь в памяти создано 5 ячеек).


- _Или всё сразу:_ `int[] numbers = new int[5];`


#### 3. Работа с ячейками и индексация

Это самое важное: **отсчет в программировании начинается с НУЛЯ.**

- В массиве на 10 элементов индексы будут от `0` до `9`.
    
- **Запись данных:** `numbers[0] = 100;` (положили 100 в первую ячейку).
    
- **Чтение данных:** `int x = numbers[0];`
    
- **Ошибка:** Если попытаться обратиться к `numbers[10]` в массиве из 10 элементов, программа «упадет» с ошибкой `ArrayIndexOutOfBoundsException`.


#### 4. Длина массива

У каждого массива есть встроенная переменная `length`, которая знает его размер.

- `int size = numbers.length;`
    
- Это супер-полезно для циклов: `for (int i = 0; i < numbers.length; i++)`. Так мы гарантированно не вылезем за границы массива.


#### 5. Быстрая (статическая) инициализация

Если ты заранее знаешь, какие данные будут в массиве, можно не писать `new int[размер]`, а просто перечислить их в фигурных скобках:

- `int[] digits = {1, 2, 3, 4, 5};` — Java сама посчитает, что их 5, и создаст массив нужного размера.
    
- `String[] colors = {"Red", "Green", "Blue"};`


#### 6. Значения по умолчанию

Когда ты создаешь массив через `new`, ячейки не остаются пустыми. Java сразу кладет туда «заглушки»:

- Для чисел (`int`, `double`) — это **0** или **0.0**.
    
- Для `boolean` — это **false**.
    
- Для ссылочных типов (например, `String`) — это **null** (пустота, «ничего»).

### 💡 Пояснение «от себя» (про память и Стек/Кучу):

Помнишь, мы говорили про Стек и Кучу? Массивы — отличный пример того, зачем это разделение нужно.

1. **В Стике** лежит только маленькая переменная-ссылка (адрес начала «полки»).
    
2. **В Куче** лежит сама «полка» со всеми данными.
    
3. **Почему это круто?** Когда ты передаешь массив в другую часть программы, ты не копируешь все 1000 его элементов. Ты просто передаешь маленькую записку с адресом: «Массив лежит вон там». Это делает Java очень быстрой.


**Тонкий момент:** Если ты напишешь `int[] a = {1, 2, 3}; int[] b = a;`, а потом изменишь `b[0] = 99;`, то в массиве `a` значение тоже изменится! Потому что и `a`, и `b` — это две разные записки, в которых написан **один и тот же адрес** в Куче. Они смотрят на одну и ту же полку.
