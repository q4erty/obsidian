В лекции рассматриваются два исторических этапа работы с датами в Java:

1. **Устаревший (но используемый)**: Классы `Date` и `Calendar`.
    
2. **Современный (Java 8 Date Time API)**: Пакет `java.time` (`LocalDate`, `LocalTime` и др.).
    

---

# Часть 1. Классический подход (Legacy)

## 1. Класс `Date`

Исторически первый класс для работы со временем. Хранит дату как количество миллисекунд, прошедших с **1 января 1970 года** (Unix Epoch). Для хранения используется тип `long`.

### Создание объекта

- **Текущая дата:** `new Date()` — инициализируется моментом создания объекта .
    
- **Конкретная дата:** `new Date(год, месяц, день, ...)`.


### Критические нюансы и недостатки `Date`:

При создании конкретной даты нужно учитывать неочевидные правила отсчета:

1. **Год:** Задается относительно 1900 года. (Чтобы получить 2021 год, нужно передать `121` -> 2021 - 1900) .
    
2. **Месяц:** Нумерация начинается с **нуля** (Январь = 0, Декабрь = 11).
    
3. **Дни:** Нумеруются с единицы.
    

### Изменение и получение данных

Класс `Date` является **изменяемым (mutable)**. У него есть методы get/set для отдельных полей (год, месяц, часы и т.д.).

- `getYear()`, `setYear(int year)` — работа с годом (от 1900).
    
- `getMonth()`, `setMonth(int month)` — работа с месяцем (с 0).
    
- `getHours()`, `getMinutes()`, `getSeconds()` — работа со временем .
    

Для форматирования вывода (преобразования в строку) используется вспомогательный класс `SimpleDateFormat` (в презентации упомянут как `DateFormat`).

---

## 2. Класс `Calendar`

Был введен как более совершенная замена `Date` для работы со сложной календарной арифметикой. Класс абстрактный, чаще всего используется его реализация `GregorianCalendar`.

- **Создание:** `Calendar.getInstance()` (возвращает календарь с текущим временем и настройками локали) или `new GregorianCalendar(...)`.
    
- **Работа с полями:** Используется универсальный метод `get(константа)` и `set(константа, значение)`.
    
    - Константы: `Calendar.YEAR`, `Calendar.MONTH`, `Calendar.DAY_OF_MONTH` и т.д. .
        
- **Особенности:** Месяцы в `Calendar` по-прежнему нумеруются с нуля.

# Часть 2. Современный Java Date Time API (Java 8+)

Современные классы находятся в пакете `java.time`. Главное отличие от `Date` — все объекты этого API **неизменяемые (immutable)**. Любой метод изменения (например, `plusDays`) возвращает **новый** объект, а не меняет текущий .

## 1. `LocalDate`

Хранит только дату (год, месяц, день) без времени и часового пояса.

- **Создание:**
    
    - `LocalDate.now()` — текущая дата.
        
    - `LocalDate.of(2019, Month.FEBRUARY, 22)` — конкретная дата.
        
    - **Важно:** Месяцы нумеруются с **единицы** (Январь = 1).
        
- **Получение данных:** `getYear()`, `getMonth()`, `getDayOfWeek()`, `getDayOfYear()` и др. .
    
- **Арифметика:** Методы `plusDays()`, `minusMonths()`, `plusWeeks()` и т.д. позволяют легко добавлять и отнимать интервалы .
    

## 2. `LocalTime`

Хранит только время (часы, минуты, секунды, наносекунды) без даты.

- **Создание:** `LocalTime.now()` или `LocalTime.of(часы, минуты, ...)`.
    
- **Получение данных:** `getHour()`, `getMinute()`, `getNano()` .
    
- **Арифметика:** `plusHours()`, `minusSeconds()` и т.д. .
    

## 3. `LocalDateTime`

Гибрид, хранящий и дату, и время.

- Объединяет методы `LocalDate` и `LocalTime`.
    
- Создание: `LocalDateTime.of(год, месяц, день, часы, минуты...)`.
    

---

## 4. `Instant` (Машинное время)

Класс для работы с метками времени (timestamp). Ориентирован на внутренние процессы компьютера.

- Хранит количество секунд с Unix Epoch (1970-01-01) и наносекунды .
    
- **Создание:**
    
    - `Instant.now()`
        
    - `Instant.ofEpochSecond(long)` или `ofEpochMilli(long)` .
        
- **Использование:** Удобен для измерения дельты времени выполнения процессов, логирования.


---

## 5. `ZonedDateTime` (Часовые пояса)

Самый полный класс, который хранит дату, время и **временную зону (Time Zone)**.

- Для работы с зонами используется класс `ZoneId`. В мире существует около 599 зон.
    
- Пример создания:
    
    Java
    
    ```
    ZoneId zone = ZoneId.of("Africa/Cairo");
    ZonedDateTime time = ZonedDateTime.now(zone); 
    // Вывод: 2019-02-22T11:37...[Africa/Cairo] [cite: 1253]
    ```

# Часть 3. Форматирование и Парсинг

Для преобразования объектов `java.time` в строку и обратно используется класс **`DateTimeFormatter`**.

### Шаблоны форматирования

Создается форматтер через `DateTimeFormatter.ofPattern("шаблон")`. Основные символы шаблонов :

- `y` — год (yyyy = 2025).
    
- `M` — месяц (MM = 02, MMM = Feb, MMMM = February).
    
- `d` — день месяца.
    
- `H` — часы (0-23). `h` — часы (1-12 AM/PM).
    
- `m` — минуты.
    
- `s` — секунды.
    

Примеры использования:

1. **Форматирование (Object -> String):**
    
    Java
    
    ```
    // Метод format вызывается у объекта даты
    String str = date.format(formatter); 
    ```
    
2. **Парсинг (String -> Object):**
    
    Java
    
    ```
    DateTimeFormatter dtf = DateTimeFormatter.ofPattern("MMMM-dd-yyyy");
    LocalDate date = LocalDate.parse("February-23-2019", dtf);
    ```
