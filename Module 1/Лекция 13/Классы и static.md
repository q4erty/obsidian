## 1. Статические переменные (Static Variables)

Статические переменные — это переменные, которые принадлежат самому классу, а не его конкретным экземплярам.

- **Механизм работы:** При загрузке класса в память Java сразу создает специальный «статический объект класса», в котором и хранятся эти переменные.
    
- **Жизненный цикл:** Статический объект существует всегда, даже если вы не создали ни одного обычного объекта (экземпляра) этого класса.
    
- **Объявление:** Используется ключевое слово `static`: `static Тип имя = значение;`.
    
- **Доступ:** * Внутри своего класса — просто по имени.
    
    - Из других классов — через имя класса: `ИмяКласса.переменная`.

### Отличие от обычных переменных

|**Характеристика**|**Обычные переменные**|**Статические переменные**|
|---|---|---|
|**Привязка**|К объекту (экземпляру)|К статическому объекту класса|
|**Количество копий**|У каждого объекта своя копия|Существуют только в одном экземпляре|

> **Дополнение:** Статические переменные часто используют для констант (например, число $\pi$) или для счетчиков, которые должны быть общими для всех созданных объектов.

---

## 2. Статические методы (Static Methods)

Статические методы также привязаны к классу, а не к его объектам.

- **Главное ограничение:** Статический метод может обращаться **только** к статическим переменным и другим статическим методам.
    
- **Вызов:** Статический метод можно вызвать напрямую у класса. Обычный метод вызвать у класса нельзя — только у конкретного объекта.


Сравнительная таблица методов

|**Способность**|**Обычный метод**|**Статический метод**|
|---|---|---|
|Связь с экземпляром класса|Да|Нет|
|Вызов обычных методов|Да|Нет|
|Вызов статических методов|Да|Да|
|Доступ к обычным переменным|Да|Нет|
|Доступ к статическим переменным|Да|Да|
|Можно вызвать у объекта|Да|Да|
|Можно вызвать у класса|Нет|Да|

## 3. Внутренние и вложенные классы

Java позволяет объявлять классы внутри других классов (иерархия может быть многоуровневой).

1. **Статические вложенные классы (Static nested classes):** Объявляются с модификатором `static`.
    
2. **Нестатические внутренние классы (Inner classes):** Обычные классы внутри других.


### Особенности статических вложенных классов

- Они ведут себя как обычные классы, и к ним можно обращаться из нестатических методов без ограничений.
    
- **Синтаксис обращения:** `КлассВнешний.ВложенныйКласс`.
    
- **Создание объекта:** `КлассВнешний.ВложенныйКласс имя = new КлассВнешний.ВложенныйКласс();`.
    
- **Доступ к элементам:** Через цепочку имен можно вызывать статические методы или переменные вложенного класса.


> **Важный нюанс:** Если вынести статический вложенный класс в отдельный файл, он потеряет возможность обращаться к `private static` переменным и методам своего бывшего «родителя».

## 4. Порядок инициализации

При создании объекта класса, содержащего внутренний класс, соблюдается строгая последовательность выполнения блоков кода и конструкторов:

1. **Статика внешнего класса:** Статические блоки и поля внешнего класса (в порядке появления).
    
2. **Статика внутреннего класса:** Статические блоки и поля внутреннего класса.
    
3. **Внешний класс (экземпляр):** Нестатические блоки инициализации и поля внешнего класса.
    
4. **Конструктор внешнего класса**.
    
5. **Внутренний класс (экземпляр):** Нестатические блоки инициализации и поля внутреннего класса.
    
6. **Конструктор внутреннего класса**.


**Общее правило:** Сначала всегда отрабатывает всё статическое, затем — нестатическое; при этом внешний класс всегда имеет приоритет перед внутренним.
