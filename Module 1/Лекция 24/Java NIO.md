## 1. Паттерн «Декоратор» (Вспоминаем «Матрешку»)

Мы уже видели этот принцип в прошлой лекции, но теперь назвали его правильно.

- **Суть:** Мы берем простой объект и «обертываем» его в другой, чтобы добавить новые способности.
    
- **Пример из жизни:** Человек (основа) -> надел свитер (декоратор "тепло") -> надел дождевик (декоратор "сухо"). Человек тот же, но свойства изменились.
    
- **В Java:** `FileInputStream` (просто читает) -> `BufferedInputStream` (читает быстро и блоками).
    
- **Зачем:** Чтобы не создавать миллион классов на все случаи жизни (типа `BufferedZipEncryptedInputStream`), мы просто комбинируем нужные обертки.

## 2. Java IO vs Java NIO

Раньше (Java 1.0) была библиотека **IO** (`java.io`). Потом (Java 1.4 и Java 7) появилась **NIO** (`java.nio` - New IO).

| **Старый подход (java.io)**                         | **Новый подход (java.nio)**                              |
| --------------------------------------------------- | -------------------------------------------------------- |
| Главный класс: **File**                             | Главный интерфейс: **Path** + класс **Files**            |
| Блокирующий (программа ждет, пока файл прочитается) | Неблокирующий (можно делать дела, пока данные грузятся)  |
| Менее удобная работа с путями и ошибками            | Очень мощная работа с путями, копированием и метаданными |

> **Вердикт:** Для работы с файловой системой сейчас **всегда** лучше использовать NIO (`Path` и `Files`).

## 3. Path и Paths (Адрес файла)

В старой Java мы писали `new File("C:\\file.txt")`. Теперь мы используем интерфейс `Path`.

- **Path (Путь)** — это просто «адрес» файла в памяти. Это **не сам файл**.
    
    - Создание такого объекта **не создает** файл на диске. Это просто бумажка, на которой написано, где файл _должен_ лежать.
        
    - Она работает одинаково хорошо и на Windows (`C:\...`), и на Linux (`/home/...`).
    
- **Как создать путь:**

```java
    // Современный способ (с Java 11)
    Path path1 = Path.of("c:\\projects\\note.txt"); 
    
    // Чуть более старый способ (но тоже NIO)
    Path path2 = Paths.get("c:\\projects\\note.txt"); 
```


### Абсолютный vs Относительный путь

- **Абсолютный:** Полный адрес от корня диска. Точно указывает на место.
    
    - _Пример:_ `C:\Users\Ivan\Documents\report.txt`

- **Относительный:** Адрес относительно того места, где ты сейчас находишься (рабочей папки проекта).
    
    - _Пример:_ `src\main\java` (без буквы диска).

## 4. Класс Files (Швейцарский нож)

Если `Path` — это просто адрес, то класс `Files` (обрати внимание на **s** в конце) — это рабочий, который ходит по этому адресу и делает дела.

Это **утилитарный класс**, все методы в нем статические.

### Самые популярные методы:

1. **Проверка:**
    
    - `Files.exists(path)` — существует ли такой файл?
        
    - `Files.createFile(path)` — создать пустой файл.
        
    - `Files.createDirectory(path)` — создать папку.
        
2. **Действия:**
    
    - `Files.copy(source, target)` — копировать файл.
        
    - `Files.move(source, target)` — переместить (или переименовать).
        
    - `Files.delete(path)` — удалить.
        
3. **Чтение и запись (Для небольших файлов):**
    
    - `Files.readString(path)` — прочитать весь файл сразу в одну строку.
        
    - `Files.readAllBytes(path)` — прочитать файл в массив байтов.
        
    - `Files.writeString(path, "Hello")` — записать строку в файл.
        

> **Важно:** Методы `readString` и `readAllBytes` загружают ВЕСЬ файл в оперативную память. Если файл весит 10 ГБ — программа упадет. Для больших файлов по-прежнему нужны потоки (Streams).

---

## 5. Как получить поток из Path?

Если файл большой и нам нужен поток (`InputStream`), мы просим его у класса `Files`:


```java
// Правильный способ в современном мире:
InputStream stream = Files.newInputStream(path); 
```

_Почему не `new FileInputStream(file)`?_ Потому что метод `Files.newInputStream` лучше обрабатывает ошибки и работает правильнее с точки зрения системы.

---

## 6. Просмотр папки (DirectoryStream)

Как узнать, какие файлы лежат внутри папки?

Используем `Files.newDirectoryStream(path)`. Это работает как цикл `for-each`:


```java
Path dir = Path.of("C:\\Windows");

try (DirectoryStream<Path> files = Files.newDirectoryStream(dir)) {
    for (Path entry : files) {
        System.out.println(entry); // Выведет список всех файлов в папке
    }
}
```

### Итог лекции:

1. Забудь про класс `File`, используй `Path`.
    
2. `Path` — это адрес, `Files` — это инструмент для работы.
    
3. Для простых операций (прочитать текст, скопировать файл) используй методы `Files`.
    
4. Для сложных операций с большими данными используй потоки, созданные через `Files.newInputStream`.
