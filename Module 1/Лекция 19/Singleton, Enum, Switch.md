## 1. Новый тип данных — Enum (Перечисление)

**Enum** (сокращение от _Enumeration_) — это особый тип данных в Java, который представляет собой фиксированный набор именованных констант.

### Основные положения:

- Используется, когда переменная должна принимать значения только из заранее определенного списка (например: дни недели, времена года, статусы заказа, стороны света).
    
- **Синтаксис:** Создается через ключевое слово `enum`.
    
- **Имена констант:** По общепринятому стандарту (CamelCase для классов и UPPER_CASE для констант) пишутся заглавными буквами.
    
- **Тип данных:** Каждая константа в enum — это объект этого самого типа `enum`.


### Ключевые методы Enum:

В презентации упоминаются важные встроенные возможности:

1. **`values()`**: Статический метод, который возвращает массив всех констант этого перечисления в том порядке, в котором они объявлены.
    
    - _Пример:_ `Day[] days = Day.values();`
        
2. **`ordinal()`**: Метод, возвращающий порядковый номер константы (начинается с **0**).
    
    - _Важно:_ Не рекомендуется завязывать бизнес-логику на порядковые номера, так как при добавлении новой константы в середину списка все номера изменятся.

## 2. Паттерн Singleton (Одиночка)

**Singleton** — это шаблон проектирования, который гарантирует, что у класса будет **только один единственный экземпляр** на всё приложение, и предоставляет к нему глобальную точку доступа.

### Зачем он нужен?

Для объектов, которые должны существовать в единственном экземпляре: общие настройки приложения, пул соединений с базой данных, логгер.

### Реализация (Классический вариант из лекции):

Чтобы создать Singleton, нужно выполнить три условия:

1. **Приватный конструктор:** `private Singleton() {}` — запрещает создание объектов через `new` из других классов.
    
2. **Приватная статическая переменная:** хранит тот самый единственный объект класса.
    
3. **Публичный статический метод (обычно `getInstance()`):**
    
    - Если объект еще не создан, метод создает его.
        
    - Если уже создан — возвращает существующий.
        

### Enum как Singleton (Дополнение):

В Java создание Singleton через `enum` считается самым надежным способом, так как он защищен от проблем многопоточности и взлома через рефлексию «из коробки».

## 3. Оператор множественного выбора — Switch

Оператор `switch` позволяет сравнивать переменную с несколькими возможными значениями и выполнять соответствующий блок кода. Это более аккуратная альтернатива длинным цепочкам `if-else if`.

### Структура и ключевые слова:

- **`switch(выражение)`**: В скобках указывается переменная, которую мы проверяем.
    
- **`case значение:`**: Блок кода, который выполнится, если выражение совпало со значением.
    
- **`break;`**: **Критически важная команда.** Она прерывает работу `switch`. Если забыть `break`, программа «провалится» дальше и начнет выполнять код во всех следующих `case` подряд, пока не встретит `break` или конец блока.
    
- **`default:`**: Аналог ветки `else`. Выполняется, если ни один из `case` не подошел. Если `default` нет и совпадений не найдено — программа просто пойдет дальше.


### Что можно использовать в switch? (Важные ограничения)

В качестве аргумента и значений `case` можно использовать только:

1. **Целые типы:** `byte`, `short`, `int` (но **не** `long`).
    
2. **Символьный тип:** `char`.
    
3. **Строки:** `String` (начиная с Java 7).
    
4. **Перечисления:** `enum`.
    
5. **Обертки примитивов:** `Byte`, `Short`, `Character`, `Integer`.


**Важно:** Типы с плавающей точкой (`float`, `double`) и тип `boolean` в `switch` использовать **нельзя**.

## 4. Сочетание Enum и Switch

Это «золотой стандарт» использования этих инструментов вместе.

- Когда мы используем `enum` в `switch`, нам не нужно писать имя класса перед константой (пишем `case MONDAY:`, а не `case Day.MONDAY:`).
    
- Это делает код максимально защищенным: вы не сможете передать в `switch` случайное значение, которое не предусмотрено в `enum`.    

### Резюме по Switch:

- `switch` делает код чище.
    
- Всегда помните про `break`.
    
- Используйте `default` для обработки непредвиденных ситуаций.
