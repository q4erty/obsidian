## 1. Понятие коллекций и их классификация

**Коллекции (контейнеры)** — это классы, позволяющие хранить и обрабатывать группы объектов. В отличие от массивов, они обладают гибкой логикой и динамическим размером.

### Основные типы коллекций в Java:

| **Тип коллекции**   | **Классы-реализации**                        | **Описание**                                                |
| ------------------- | -------------------------------------------- | ----------------------------------------------------------- |
| **List (Списки)**   | `ArrayList`, `LinkedList`, `Vector`, `Stack` | Хранят элементы в порядке добавления, допускают дубликаты.  |
| **Set (Множества)** | **`HashSet`**, `TreeSet`, `LinkedHashSet`    | Хранят только уникальные элементы (без дублей).             |
| **Queue (Очереди)** | `PriorityQueue`, `ArrayQueue`                | Работают по принципу очереди (первым пришел — первым ушел). |
| **Map (Словари)**   | `HashMap`, `TreeMap`, `Hashtable`            | Хранят пары «ключ — значение».                              |


---

## 2. Множество (Set) и класс HashSet

**Set** — это абстракция «множества» из математики. Главное свойство: **один и тот же объект не может встретиться в сете дважды.**

**HashSet:**

- Основан на хеш-таблицах.
    
- **Порядок элементов не гарантируется** (при выводе на экран элементы могут стоять не так, как вы их добавляли).
    
- Очень быстрый поиск, добавление и удаление.


### Методы класса HashSet:

| **Метод**                        | **Описание**                                                          |
| -------------------------------- | --------------------------------------------------------------------- |
| `boolean add(T value)`           | Добавляет элемент. Возвращает `false`, если такой элемент уже есть.   |
| `boolean remove(Object value)`   | Удаляет элемент. Возвращает `true`, если элемент был найден и удален. |
| `boolean contains(Object value)` | Проверяет, есть ли такой элемент в множестве.                         |
| `void clear()`                   | Полностью очищает коллекцию.                                          |
| `boolean isEmpty()`              | Проверяет, пуста ли коллекция (`size == 0`).                          |
| `int size()`                     | Возвращает количество элементов.                                      |

## 3. Итератор (Iterator)

Поскольку у `Set` нет индексов (в отличие от `ArrayList`), мы не можем использовать обычный цикл `for(int i...)`. Для обхода элементов используется **Итератор** — специальный объект-указатель.

**Основные методы итератора:**

1. **`hasNext()`**: возвращает `true`, если в коллекции остались элементы, которые мы еще не прошли.
    
2. **`next()`**: возвращает следующий элемент и передвигает «указатель» вперед.


---

## 4. Цикл for-each

Это «синтаксический сахар» над итератором. Он позволяет обходить коллекцию проще:


```java
for (Тип имя : коллекция) {
    // действия с переменной "имя"
}
```

**Механизм:** Внутри этого цикла Java неявно создает итератор и сама вызывает методы `hasNext()` и `next()`.

## 5. Проблема удаления элементов в цикле

**Важнейшее правило:** Нельзя менять (удалять/добавлять элементы) коллекцию напрямую, пока вы обходите её с помощью итератора (включая цикл `for-each`). Это приведет к ошибке `ConcurrentModificationException`.

### 3 способа правильно удалить элементы из коллекции:

1. **Использование копии коллекции:**
    
    Вы создаете копию сета, бежите по ней через `for-each`, а удаляете элементы из **оригинала**.

```java
    Set<Integer> copy = new HashSet<>(numbers);
    for (Integer n : copy) {
        if (n < 0) numbers.remove(n);
    }
```

1. **Явное использование итератора:**
	
    Только у самого объекта `Iterator` есть метод `remove()`, который безопасно удаляет текущий элемент.


```java
    Iterator<Integer> it = numbers.iterator();
    while (it.hasNext()) {
        if (it.next() < 0) it.remove();
    }
```

2. **Использование другого типа цикла:**
	
    Для `ArrayList` это цикл `for` с индексом (но для `Set` этот способ не подходит, так как в сете нет индексов).


---

### Дополнение: почему HashSet не сохраняет порядок?

В презентации это не объяснено подробно: `HashSet` использует `hashCode()` объекта, чтобы вычислить «корзину» (индекс в массиве), куда положить данные. Это позволяет моментально находить элемент по его коду, вместо того чтобы перебирать весь список. Именно поэтому при выводе на экран элементы «прыгают» — они располагаются согласно своим хеш-кодам, а не времени добавления.
