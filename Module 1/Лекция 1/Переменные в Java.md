### Что такое переменная?

**Переменная** — это именованная область памяти для хранения данных. Чтобы отличать одну переменную от другой, ей дают **имя**.

Каждая переменная имеет три основные характеристики:

1. **Тип:** определяет, какие именно данные могут в ней храниться.
    
2. **Имя:** уникальный идентификатор для обращения к данным.
    
3. **Значение:** конкретная информация, которая находится в этой области памяти.


---

### Создание и объявление переменных

Для создания переменной используется команда вида: `тип имя;`.

**Базовые типы данных:**

- **`int`** — для целых чисел (например, `int a;`).
    
- **`String`** — для текста (например, `String s;`).
    
- **`double`** — для дробных чисел (например, `double c;`).


**Особенности объявления:**

- Можно объявить несколько переменных одного типа через запятую: `int a, b, c;`.
    
- **Запрещено** создавать две переменные с одинаковыми именами в рамках одного метода.


---

### Операция присваивания

Для записи значения в переменную используется символ `=`.

- **Команда:** `имя = значение;`.
    
- Значение справа от знака `=` копируется в переменную, указанную слева.
    
- **Инициализация:** можно объявить переменную и сразу присвоить ей значение: `String name = "Аня";`.


---

### Правила именования

- **Регистр важен:** переменные `color` и `Color` — это две разные переменные.
    
- **Символы:** имя не может содержать пробелы и математические знаки (`+`, `-` и т.д.).
    
- **Рекомендация:** лучше всего использовать только латинские буквы и цифры.


---

### Работа с числами (тип `int`)

- **Диапазон:** от -2,147,483,648 до 2,147,483,647.
    
- **Деление целых чисел:** в Java результат деления целого на целое всегда будет целым числом (дробная часть отбрасывается).
    
    - Пример: `int d = 1 / 2;` даст результат `0`.
    
- **Остаток от деления (`%`):** используется для получения остатка. Например, `5 % 2` даст `1`.
    
- **Инкремент (`++`) и декремент (`--`):** быстрые команды для увеличения или уменьшения значения переменной на единицу.


---

### Работа со строками (тип `String`)

- **Конкатенация:** это «склеивание» строк с помощью знака `+`.
    
    - Пример: `"Hello! " + "Аня"` превратится в `"Hello! Аня"`.
    
- **Преобразование типов:**
    
    - Если сложить `String` и число, число автоматически станет строкой: `"Аня" + 5` → `"Аня5"`.
    
    - Чтобы превратить строку из цифр в число, используется: `int x = Integer.parseInt(строка);`.


---

### Полезные методы для строк

1. **`name.length()`** — возвращает количество символов в строке.
    
2. **`name.toLowerCase()`** — переводит все буквы в нижний регистр.
    
3. **`name.toUpperCase()`** — переводит все буквы в верхний регистр.
