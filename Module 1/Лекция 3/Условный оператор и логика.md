#### 1. Оператор `if` (Выбор пути)

Программа проверяет условие. Если оно **истинно (true)**, выполняется блок кода.

- **Одиночный `if`**: «Если пойдет дождь — возьми зонт».
    
- **Конструкция `if-else`**: «Если есть деньги — купи кофе, иначе — иди работать».
    
- **Цепочка `if-else if-else`**: Позволяет проверить несколько условий по очереди. Программа выполнит только **первый** блок, условие которого совпало, и выйдет из всей цепочки.


#### 2. Блоки команд `{ }`

- Если внутри `if` только одна команда, фигурные скобки можно не ставить.
    
- **Но лучше ставить их всегда!** Это защищает от ошибок, когда вы захотите добавить вторую команду, а она выполнится сама по себе, без привязки к условию.


#### 3. Тип `boolean` и операторы сравнения

Условие внутри `if` всегда должно превращаться в тип `boolean` (`true` или `false`). **Как мы сравниваем:**

- `a == b` — равно (внимание: два знака равно!).
    
- `a != b` — не равно.
    
- `> / <` — больше / меньше.
    
- `>= / <=` — больше или равно / меньше или равно.


#### 4. Логические связки (Сложные условия)

Когда одного условия мало (например, «если я голоден **И** у меня есть деньги»):

- **`&&` (И / AND)**: результат `true`, только если **оба** условия верны.
    
- **`||` (ИЛИ / OR)**: результат `true`, если верно **хотя бы одно** из условий.
    
- **`!` (НЕ / NOT)**: переворачивает результат (был `true` — стал `false`).


#### 5. Тернарный оператор

Это сокращенная запись `if-else` для простых случаев. **Формула:** `переменная = (условие) ? значение1 : значение2;`

- Если условие верно — берем `значение1`.
    
- Если нет — `значение2`.
    
- _Пример:_ `String result = (age >= 18) ? "Взрослый" : "Ребенок";`


#### 6. Сравнение строк (ВАЖНО!)

Это то самое место, где знание про **Стек и Кучу** спасает от багов:

- **Примитивы (`int`, `double`)** сравниваем через `==`. Мы сравниваем значения в Стике.
    
- **Строки (`String`)** сравниваем через **`.equals()`**.
    
    - Если написать `s1 == s2`, Java сравнит **адреса** (ссылки). Даже если текст одинаковый, ссылки могут быть разными.
        
    - `s1.equals(s2)` идет по ссылке в Кучу и проверяет буквы одну за другой.

### 💡 Пояснение «от себя» (почему это важно):

**Ловушка со String Pool:** В лекции есть нюанс: если ты напишешь в коде: `String s1 = "Привет";` `String s2 = "Привет";` То `s1 == s2` внезапно выдаст `true`. Почему? Потому что Java-компилятор увидел одинаковые строки и в целях экономии (String Pool) дал им **один и тот же адрес**.

**НО!** Если одну строку введет пользователь через `Scanner`, а вторая будет в коде — их адреса будут **разными**, и `==` выдаст `false`, хотя текст один и тот же. **Золотое правило:** Всегда используй `.equals()`, чтобы не гадать, сработала оптимизация памяти или нет.

**Вложенные if:** Ты можешь засунуть один `if` внутрь другого. Это называется вложенностью. Но старайся не делать «матрешку» глубже 2-3 уровней, иначе код станет невозможно читать (это называют «адским кодом»).
