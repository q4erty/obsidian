## 1. Введение в Map

**Map** — это коллекция, представляющая собой множество пар **«ключ-значение»**.

- **Терминология:** Официально называется «ассоциативный массив», но также часто используются названия «словарь», «карта» или сленговое «мапа».
    
- **Принцип хранения:** Данные хранятся парами. Ключи и значения могут быть любыми объектами (строки, числа, пользовательские классы).
    
- **Важное уточнение:** В Map ключи всегда **уникальны**. Если вы попытаетесь добавить значение по уже существующему ключу, старое значение будет перезаписано новым.

## 2. HashMap

**HashMap** — самая популярная реализация интерфейса Map. Она похожа на `HashSet` по внутренней логике и на `ArrayList`, если бы индексами могли быть любые объекты, а не только числа.

### Создание и типы:

Java

```
HashMap<ТипКлюча, ТипЗначения> map = new HashMap<>(); [cite: 24]
```

Основные методы HashMap:

| **Метод**              | **Описание**                                               |
| ---------------------- | ---------------------------------------------------------- |
| `put(key, value)`      | Добавляет пару в коллекцию.                                |
| `get(key)`             | Возвращает значение по ключу (или `null`, если ключа нет). |
| `containsKey(key)`     | Проверяет, есть ли такой ключ в коллекции.                 |
| `containsValue(value)` | Проверяет наличие конкретного значения.                    |
| `remove(key)`          | Удаляет пару по ключу и возвращает удаленное значение.     |
| `size()`               | Возвращает количество пар в коллекции.                     |
| `clear()`              | Полностью очищает коллекцию.                               |
| `keySet()`             | Возвращает набор (`Set`) всех ключей.                      |
| `values()`             | Возвращает коллекцию (`Collection`) всех значений.         |
| `entrySet()`           | Возвращает набор пар (`Set<Map.Entry>`).                   |

### Итерация (перебор) HashMap:

Так как у элементов нет порядкового номера, обычный цикл `for` с индексом не подходит. Используются следующие способы:

1. **По ключам:** Получить `keySet()` и пройтись по нему циклом `for-each`.
    
2. **По парам:** Использовать `entrySet()`, что эффективнее, если вам нужны и ключи, и значения одновременно.

## 3. TreeMap

**TreeMap** — это реализация Map, которая автоматически **сортирует элементы по ключам**.

- **Сортировка:** По умолчанию используется «natural ordering» (естественный порядок, например, по алфавиту или по возрастанию чисел).
    
- **Comparable и Comparator:** Чтобы объекты могли быть ключами, их класс должен реализовывать интерфейс `Comparable`. Если это невозможно, при создании `TreeMap` нужно передать свой объект-компаратор (`Comparator`).
    
- **Особенность Null:** В `TreeMap` можно использовать `null` в качестве ключа только в том случае, если вы явно определили компаратор, который знает, как обрабатывать `null`. В противном случае возникнет `NullPointerException`.

## 4. Сравнение производительности и рекомендации

Выбор коллекции зависит от конкретной задачи. Ниже приведена сложность операций (в нотации O-большое):

|**Коллекция**|**Доступ по ключу**|**Поиск**|**Вставка**|**Удаление**|
|---|---|---|---|---|
|**ArrayList**|O(1) (по индексу)|O(n)|O(1) (в конец)|O(n)|
|**HashSet**|O(1)|O(1)|O(1)|O(1)|
|**HashMap**|O(1)|O(1)|O(1)|O(1)|
|**TreeMap**|O(1)|O(log n)|O(log n)|O(log n)|

**Когда что использовать?**

- **ArrayList:** если нужен список с доступом по индексу и возможными повторами.
    
- **HashSet:** если нужны только уникальные элементы и порядок не важен.
    
- **HashMap:** если нужно хранить пары «объект-объект» для быстрого поиска.

## 5. Вспомогательный класс Collections

Класс `java.util.Collections` содержит статические методы для работы с коллекциями.

### Изменение и создание:

- `addAll(colls, e1, e2...)`: добавляет произвольное число элементов в коллекцию.
    
- `fill(list, obj)`: заменяет все элементы в списке на `obj`.
    
- `nCopies(n, obj)`: создает неизменяемый «фиктивный» список из `n` повторений объекта.
    
- `replaceAll(list, old, new)`: заменяет все вхождения `oldValue` на `newValue`.
    
- `copy(dest, src)`: копирует элементы из одного списка в другой.


### Поиск и анализ:

- `min()` / `max()`: находит минимальный или максимальный элемент .
    
- `frequency(colls, obj)`: считает, сколько раз объект встречается в коллекции.
    
- `binarySearch(colls, obj)`: ищет элемент в **отсортированной** коллекции (возвращает индекс или отрицательное число).
    
- `disjoint(coll1, coll2)`: возвращает `true`, если у коллекций нет общих элементов.


### Порядок элементов:

- `reverse(list)`: переворачивает список задом наперед.
    
- `sort(list)`: сортирует по возрастанию.
    
- `shuffle(list)`: перемешивает элементы в случайном порядке.
    
- `rotate(list, distance)`: циклически сдвигает элементы на заданное число позиций.
