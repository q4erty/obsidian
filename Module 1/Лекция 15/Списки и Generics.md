## 1. Типы-обертки (Wrapper Types)

В Java примитивные типы (например, `int`) не являются объектами. Для работы с ними в коллекциях (таких как `ArrayList`) используются специальные классы-обертки.

Соответствие типов :

| **Примитив** | **Класс-обертка** | **Примитив** | **Класс-обертка** |
| ------------ | ----------------- | ------------ | ----------------- |
| `byte`       | `Byte`            | `float`      | `Float`           |
| `short`      | `Short`           | `double`     | `Double`          |
| `int`        | **`Integer`**     | `char`       | **`Character`**   |
| `long`       | `Long`            | `boolean`    | `Boolean`         |

Autoboxing и Unboxing

- **Autoboxing (Автоупаковка):** Автоматическое преобразование примитива в объект. Пример: `Integer a = 10;` (компилятор вызывает `Integer.valueOf(10)`).
    
- **Unboxing (Автораспаковка):** Обратное преобразование объекта в примитив. Пример: `int b = a;` (компилятор вызывает `a.intValue()`).

## 2. Подробный разбор классов-оберток

#### Класс Integer

Поля (константы) :

- `Integer.MAX_VALUE`: Максимальное значение `int` ($2^{31}-1$).
    
- `Integer.MIN_VALUE`: Минимальное значение `int` ($-2^{31}$).


Методы :

- `static String toHexString(int i)`: Число в 16-ричную строку.
    
- `static String toBinaryString(int i)`: Число в двоичную строку.
    
- `static String toOctalString(int i)`: Число в 8-ричную строку.
    
- `static Integer valueOf(int i)`: Создает объект `Integer` из числа.
    
- `static int parseInt(String s)`: Извлекает число из строки.


#### Класс Double

Поля :

- `Double.NEGATIVE_INFINITY`: Отрицательная бесконечность.
    
- `Double.POSITIVE_INFINITY`: Положительная бесконечность.
    
- `Double.MIN_EXPONENT` / `MAX_EXPONENT`: Границы экспоненты .
    
- `Double.MIN_VALUE` / `MAX_VALUE`: Мин./макс. положительное значение .


Методы :

- `static boolean isInfinite(double d)`: Проверка на бесконечность.
    
- `static boolean isNaN(double d)`: Проверка, является ли значение «не числом» (NaN).
    
- `static Double valueOf(double d)` и `static double parseDouble(String s)` .


#### Класс Character

Методы для работы с символами любых алфавитов :

- `isAlphabetic(int)` / `isLetter(char)`: Является ли буквой .
    
- `isDigit(char)`: Является ли цифрой.
    
- `isSpaceChar(char)`: Пробел, перенос строки, смена параграфа.
    
- `isWhitespace(char)`: Любой разделитель (пробел, tab и т.д.).
    
- `isLowerCase` / `isUpperCase`: Проверка регистра .
    
- `toLowerCase` / `toUpperCase`: Смена регистра .


#### Класс Boolean

Имеет две константы: `Boolean.TRUE` и `Boolean.FALSE` .

## 3. Коллекция ArrayList

`ArrayList` — это динамический список, реализованный на основе обычного массива.

**Особенности:**

- Хранит только ссылочные типы (объекты).
    
- Индексация начинается с **0**.


Основные методы ArrayList :

|**Метод**|**Описание**|
|---|---|
|`void add(T value)`|Добавляет элемент в конец.|
|`void add(int index, T value)`|Вставляет элемент в указанную позицию.|
|`T get(int index)`|Возвращает элемент по индексу.|
|`void set(int index, T value)`|Заменяет значение в ячейке `index`.|
|`T remove(int index)`|Удаляет по индексу и возвращает удаленный объект.|
|`boolean remove(T value)`|Удаляет первый найденный такой объект.|
|`void clear()`|Полная очистка списка.|
|`boolean contains(T value)`|Проверяет наличие элемента в списке.|
|`boolean isEmpty()`|`true`, если список пуст (`size == 0`).|
|`int size()`|Текущее количество элементов.|
|`T[] toArray(T[] array)`|Преобразует список обратно в массив.|

Внутреннее устройство и расширение :

1. Внутри объекта хранятся массив и переменная `size` .
    
2. Начальный размер массива — **10 элементов**.
    
3. Если места нет, создается **новый массив в 1.5 раза больше**, в него копируются старые данные, и ссылка перебрасывается на новый массив .

## 4. Синтаксический сахар (Выведение типов)

- **Ключевое слово `var` (Java 11+):** Компилятор определяет тип сам по значению.
    
    - _Пример:_ `var list = new ArrayList<Integer>();`.
    
- **Оператор Diamond `<>` (Java 7+):** Тип можно не писать справа, если он указан слева.
    
    - _Пример:_ `ArrayList<String> list = new ArrayList<>();`.
    
- **Важно:** Не используйте `var` и `<>` одновременно (`var list = new ArrayList<>();`), иначе тип определится как `ArrayList<Object>` .

## 5. Дженерики (Generics)

Позволяют создавать сложные составные типы: `ОсновнойТип<ТипПараметр>` .

**Важные факты:**

1. **Стирание типов (Type Erasure):** После компиляции информация о параметрах теряется, остаются только сырые классы и приведения типов.
    
2. Параметров может быть несколько: `Map<K, V>`.
    
3. Параметры могут быть вложенными: `List<List<String>>`.
    
4. Можно создавать массивы дженериков: `ArrayList<String>[] array`.
