#### 1. Как компьютер хранит данные (Оперативная память)

Представь оперативную память как огромную таблицу Excel или сетку из ячеек.

- Каждая ячейка имеет свой **адрес** (номер).
    
- В одну ячейку можно положить кусочек данных.
    
- Когда мы создаем переменную, Java занимает несколько таких ячеек и дает им имя, чтобы мы не запоминали сложные адреса типа `0x7ff...`.


#### 2. Расширенный список типов данных

В Java есть «простые» (примитивные) типы. Они отличаются тем, сколько места в памяти занимают и что именно хранят:

- **Целые числа:**
    
    - `byte`: крошечное (от -128 до 127).
        
    - `short`: небольшое.
        
    - `int`: стандартное (самое частое).
        
    - `long`: огромное число (например, расстояние до звезд).
    
- **Дробные числа:**
    
    - `float`: обычная дробь.
        
    - `double`: высокая точность (используется по умолчанию).
    
- **Символы и Логика:**
    
    - `char`: один одиночный символ в одинарных кавычках (например, `'A'`).
        
    - `boolean`: только `true` (истина) или `false` (ложь).
    

#### 3. Особенности типа String (Текст)

`String` — это не примитив, а **ссылочный тип**.

- В переменной типа `int` лежит само число.
    
- В переменной типа `String` лежит **адрес** места в памяти, где записан текст.
    
- Поэтому со строками можно делать сложные штуки: `name.toUpperCase()` (сделать все буквы большими) или `name.length()` (узнать длину).


#### 4. Ввод данных с клавиатуры (`Scanner`)

Чтобы программа не просто выдавала текст, а умела «слушать» пользователя, используется объект **Scanner**.

**Как это работает:**

1. Сначала нужно «подключить» инструмент в самом верху файла:
    
    `import java.util.Scanner;`
    
2. Создать «приемник» данных:
    
    `Scanner console = new Scanner(System.in);`
    
3. Считать данные в переменную:
    
    - `String s = console.nextLine();` — читает целую строку текста.
        
    - `int n = console.nextInt();` — читает целое число.
        
    - `double d = console.nextDouble();` — читает дробное число.
    

#### 5. Что такое IntelliJ IDEA?

Это **IDE** (Integrated Development Environment) — «умный» текстовый редактор для программистов.

- Он подсвечивает ошибки (как Т9 в телефоне).
    
- Помогает дописывать код.
    
- Позволяет запускать программу одной кнопкой.
    
- **JDK** (Java Development Kit) — это «набор инструментов», который IDEA использует, чтобы превратить твой код в работающую программу.
