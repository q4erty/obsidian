## 1. Примитивные типы данных

Примитивные типы — это основа Java. Они называются «примитивными», так как их значения не являются объектами и хранятся напрямую в переменных. В Java существует **8 базовых примитивных типов**.

Если переменная объявлена как поле класса или статическая переменная, но ей не присвоено значение, она инициализируется **значением по умолчанию**.

### Таблица характеристик типов

|**Тип**|**Размер (байт)**|**Диапазон значений**|**Значение по умолчанию**|**Описание**|
|---|---|---|---|---|
|**byte**|1|-128 .. 127|0|Самое маленькое целое|
|**short**|2|-32,768 .. 32,767|0|Короткое целое|
|**int**|4|~ $-2 \cdot 10^9$ .. $2 \cdot 10^9$|0|Стандартное целое число|
|**long**|8|~ $-9 \cdot 10^{18}$ .. $9 \cdot 10^{18}$|0L|Длинное целое|
|**float**|4|$-10^{38}$ .. $10^{38}$|0.0f|Дробное число|
|**double**|8|$-10^{308}$ .. $10^{308}$|0.0d|Дробное двойной точности|
|**boolean**|1|true, false|false|Логический тип|
|**char**|2|0 .. 65,535|'\u0000'|Символы Unicode (неотрицательные)|

## 2. Особенности дробных чисел (float и double)

### Бесконечность (Infinity)

Числа с плавающей точкой позволяют хранить положительную и отрицательную бесконечность.

- `100.0 / 0.0` → **Infinity**.
    
- `-100.0 / 0.0` → **-Infinity**.
    
- Любые операции с бесконечностью (умножение, вычитание константы) обычно также дают бесконечность .


### Not a Number (NaN)

NaN («не число») возникает при неопределенных математических операциях:

- Деление бесконечности на бесконечность.
    
- Деление нуля на нуль: `0.0 / 0.0` → **NaN**.
    
- **Важно:** Любая операция с NaN в результате всегда дает NaN.

## 3. Работа с символами (char)

Значения `char` — это числа в диапазоне от 0 до 65535, соответствующие кодам таблицы **Unicode**, которая содержит знаки почти всех языков мира.

**Способы задания символа 'A' (код 65):**

- `char a = 'A';` — литерал.
    
- `char a = 65;` — десятичное число.
    
- `char a = 0x41;` — шестнадцатеричное число.
    
- `char a = '\u0041';` — специальный формат Unicode-записи.

## 4. Приведение типов (Casting)

Для визуализации используется аналогия с матрешками: в большую переменную (long) легко помещается маленькая (int) .

### Расширение типов (Widening)

Происходит **автоматически**. Переменной большего размера всегда можно присвоить значение меньшего типа.

- `byte` → `short` → `int` → `long` .
    
- Преобразования по сплошным линиям (например, `int` → `double`) идут без потери точности, по штриховым — возможна потеря информации.


### Сужение типов (Narrowing)

Требует явного указания типа в скобках — **оператор приведения (cast)** .

- **Синтаксис:** `(тип) выражение;` (например, `int b = (int) a;`).
    
- **Риски:** При сужении ответственность за корректность данных лежит на программисте. Если число не влезает в диапазон меньшего типа, произойдет отсечение бит и значение изменится (например, `10_000_000` при касте в `short` станет `-27008`).

## 5. Объекты и переменные-ссылки

Все переменные, не являющиеся примитивами, называются **ссылочными**. Они содержат не само значение, а адрес объекта в памяти.

- **null:** Значение по умолчанию для ссылочных переменных, если они не инициализированы.
    
- **Оператор new:** Используется для создания объекта (экземпляра) класса.
    
- **Синтаксис:** `Класс имя = new Класс(параметры);`.
    
- **Примеры объектов:** `String` (строка), `Scanner` (ввод данных), массивы (например, `int[]`).


### Классы

Класс — это «шаблон» или чертеж, описывающий свойства и функции будущего объекта. Переменные внутри класса называются **полями**.

- _Пример:_ Класс `Cat` с полями `name` и `age` является шаблоном для всех создаваемых котиков .
