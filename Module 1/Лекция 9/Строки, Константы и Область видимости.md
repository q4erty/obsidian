### 1. Константы и ключевое слово `final`

Если переменная помечена `final`, её значение нельзя изменить после инициализации.

- **Зачем:** Защита важных данных (число Пи, настройки сервера).
    
- **Оформление:** Имена пишутся `UPPER_CASE` через подчеркивание.
    
- **Важно:** Если `final` стоит у ссылочного типа (например, массива), нельзя заменить сам массив на другой, но **можно менять элементы** внутри этого массива.


### 2. Сокрытие переменных и ключевое слово `this`

Когда имя локальной переменной совпадает с именем переменной класса (поля), возникает **shadowing** (затенение).

- Внутри метода по умолчанию будет использоваться **локальная** переменная.
    
- Чтобы обратиться к переменной класса, используется ключевое слово **`this`**.


> `this` — это ссылка на текущий объект. Она говорит компилятору: «Возьми переменную не из этого метода, а ту, что принадлежит всему классу».

### 3. Экранирование символов (Полный список)

Поскольку Java использует спецсимволы для оформления кода, их нужно «маскировать» обратным слэшем `\`:

- `\'` — Одинарная кавычка.
    
- `\"` — Двойная кавычка.
    
- `\\` — Обратный слэш.
    
- `\n` — Переход на новую строку (самый частый).
    
- `\r` — Возврат каретки.
    
- `\t` — Табуляция (отступ).
    
- `\b` — Возврат на один символ (backspace).
    
- `\f` — Перевод страницы.
    
- `\uXXXX` — Символ Юникода (например, `\u263A` — это смайлик).


### 4. Хранение строк: Пул строк (String Pool)

Строка — это объект, но Java оптимизирует их хранение:

1. **Неизменяемость (Immutability):** Объект `String` нельзя изменить. Любой метод (`replace`, `toUpperCase`) создает **новый** объект.
    
2. **String Pool:** Это специальная область в Куче (Heap). Если ты создаешь две строки литералами `String a = "Java"; String b = "Java";`, Java создаст только один объект, и обе переменные будут ссылаться на него.
    
3. **Создание через `new`:** Если написать `String s = new String("Java");`, Java принудительно создаст новый объект в Куче, игнорируя Пул. Поэтому строки **нельзя сравнивать через `==`** (сравнятся адреса), только через `.equals()`.

### 5. Подробный справочник методов класса `String`

#### **Поиск и проверка содержания**

- `length()` — возвращает длину строки (количество символов).
    
- `isEmpty()` — `true`, если длина 0.
    
- `isBlank()` — `true`, если строка пустая или состоит только из пробелов/табуляций.
    
- `contains(String s)` — проверяет, входит ли подстрока в строку.
    
- `startsWith(String prefix)` / `endsWith(String suffix)` — проверка начала и конца.
    
- `indexOf(String s)` — индекс первого вхождения (или -1, если не найдено).
    
- `lastIndexOf(String s)` — индекс последнего вхождения.


#### **Изменение и создание подстрок**

- **`substring(int begin, int end)`** — вырезает часть с `begin` (включительно) до `end` (**не включая** его).
    
- **`replace(old, new)`** — заменяет все старые символы/строки на новые.
    
- **`replaceAll / replaceFirst`** — замена с использованием регулярных выражений.
    
- **`toLowerCase() / toUpperCase()`** — перевод регистра.
    
- **`trim()`** — обрезает пробелы в начале и конце.
    
- **`repeat(int n)`** — создает строку из `n` повторений оригинала.
    
- **`split(String regex)`** — разбивает строку на массив строк по разделителю.


#### **Сравнение**

- **`equals(Object o)`** — сравнение по буквам (с учетом регистра).
    
- **`equalsIgnoreCase(String s)`** — сравнение без учета регистра.
    
- **`compareTo(String s)`** — лексикографическое сравнение (какая строка идет раньше в словаре).

### 💡 Дополнение: чего обычно нет в слайдах, но важно знать

- **Метод `intern()`:** Если у тебя есть строка, созданная через `new` или ввод с клавиатуры, вызов `s.intern()` проверит Пул строк. Если там есть такая же строка — вернет ссылку на неё, если нет — добавит её туда.
    
- **Конкатенация в цикле:** Никогда не склеивай строки через `+` внутри длинного цикла (например, на 10 000 итераций). Так как строки неизменяемы, Java будет создавать тысячи объектов-пустышек. Для этого лучше использовать `StringBuilder`.
