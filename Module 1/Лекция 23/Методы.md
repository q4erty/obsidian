### 1. Методы для «Сырых данных» (InputStream / OutputStream)

Это методы базовых классов. Ими пользуются все наследники, работающие с байтами.

**InputStream (Труба ВХОД)**

| **Метод**        | **Что делает (простыми словами)**                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| `read()`         | Читает **один** байт. Возвращает число (код байта). Если байты кончились, вернет **-1**.         |
| `read(byte[] b)` | Читает сразу кучу байтов и складывает их в массив `b`. Возвращает количество прочитанных байтов. |
| `available()`    | Спрашивает: «Сколько байтов сейчас готово к чтению?».                                            |
| `skip(long n)`   | Пропускает `n` байтов (как перемотка фильма вперед).                                             |
| `close()`        | **Закрывает поток.** (Закручивает кран). Обязательно вызывать после работы!                      |

**OutputStream (Труба ВЫХОД)**

| **Метод**         | **Что делает (простыми словами)**                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `write(int b)`    | Записывает **один** байт.                                                                                                 |
| `write(byte[] b)` | Записывает весь массив байтов целиком.                                                                                    |
| `flush()`         | **«Смыть».** Принудительно выталкивает данные из буфера в файл. Если данные «застряли» в трубе, этот метод их протолкнет. |
| `close()`         | Закрывает поток и освобождает ресурсы.                                                                                    |

### 2. Методы для работы в памяти (ByteArray)

Эти потоки работают не с файлами, а с массивами внутри оперативной памяти.

**ByteArrayInputStream (Чтение из памяти)**

Работает почти так же, как обычный InputStream, но берет данные из массива.

- `read()` — читает следующий байт из массива.
    
- `available()` — сколько байтов осталось в массиве.
    
- `reset()` — возвращает «курсор» чтения в начало массива (можно прочитать заново).
    

**ByteArrayOutputStream (Запись в память)**

Это наш «резиновый массив», который растет по мере записи.

- `write(int b)` — добавляет байт в этот массив.
    
- `toByteArray()` — **Самый важный метод.** Превращает всё, что ты записал в поток, в обычный массив байтов (`byte[]`), который можно использовать дальше.
    
- `toString()` — превращает записанные байты в строку (текст).

### 3. Методы для удобного чтения текста

**Scanner (Удобный читатель)**

Сканнер разбивает поток на кусочки (токены) с помощью разделителя (обычно пробел). 

| Метод                          | Что делает                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `next()`                       | Читает **одно слово** (до пробела).                                                   |
| `nextLine()`                   | Читает **всю строку** целиком (до нажатия Enter).                                     |
| `nextInt()`                    | Читает следующее **целое число**. (Если там буква — упадет с ошибкой).                |
| `hasNext()`                    | Проверяет, есть ли там еще что-то (возвращает `true` или `false`). Полезно в циклах.  |
| `useDelimiter(String pattern)` | Позволяет задать свой разделитель (например, читать не по пробелам, а по запятым). \| |


**BufferedReader (Быстрый читатель)**

Используется для быстрого чтения больших текстов.

| Метод        | Что делает                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| `read()`     | Читает один символ.                                                                                            |
| `readLine()` | **Главный метод.** Читает строку целиком. Если файл закончился, вернет `null` (а не -1, как байтовые потоки).  |

### Короткий пример использования (Шпаргалка):

**Если нужно скопировать файл (байты):**

Используешь цикл: «Пока `read()` не вернет -1, делай `write()`».

**Если нужно считать число с клавиатуры:**

Java

```
Scanner sc = new Scanner(System.in);
if (sc.hasNextInt()) {       // Сначала проверяем (hasNext)
    int number = sc.nextInt(); // Потом читаем (next)
}
```

**Если нужно прочитать длинный текст из файла:**

Java

```
BufferedReader reader = ...;
String line;
while ((line = reader.readLine()) != null) { // Читаем по строке, пока не null
    System.out.println(line);
}
```
