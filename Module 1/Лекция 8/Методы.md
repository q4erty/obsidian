#### 1. Что такое метод?

**Метод** — это именованный блок кода. Вместо того чтобы писать один гигантский метод `main`, логичнее разбить его на маленькие части: например, `printReport()`, `calculateSum()`, `saveToDatabase()`.

- Это делает код читаемым.
    
- Это позволяет не дублировать код: написал один раз — вызываешь сколько угодно.


#### 2. Объявление и вызов

- **Объявление:** `public static void имяМетода() { код }`
    
- **Вызов:** Просто пишешь `имяМетода();` в нужном месте.


#### 3. Параметры методов (Входные данные)

Методу можно передать данные для работы.

- `public static void sayHello(String name)` — здесь `name` это параметр.
    
- При вызове `sayHello("Amigo");` значение "Amigo" копируется в переменную `name`.


#### 4. Передача аргументов: Примитивы vs Ссылки (ВАЖНО!)

Здесь снова вспоминаем нашу тему про память:

- **Примитивы (`int`, `double`...):** Передаются **по значению**. Метод получает _копию_ числа. Если изменить его внутри метода, оригинал снаружи не изменится.
    
- **Объекты и массивы:** Передаются **по ссылке**. Метод получает _копию адреса_ в памяти. Если ты изменишь содержимое массива внутри метода, он **изменится и снаружи**, потому что адрес ведет на тот же самый объект в Куче.


#### 5. Оператор `return` (Выходные данные)

Метод может не просто выполнить работу, но и вернуть результат.

- Если метод возвращает что-то, вместо `void` пишем тип данных (например, `int` или `String`).
    
- Команда `return` мгновенно завершает работу метода и «выбрасывает» результат обратно в место вызова.


#### 6. Перегрузка методов (Overloading)

В одном классе может быть несколько методов с **одинаковым именем**, но **разными параметрами** (по типу или количеству).

- Например: `print(int n)` и `print(String s)`. Java сама поймет, какой вызвать, глядя на то, что ты передаешь в скобках.


#### 7. Модификатор `static`

В этой лекции мы учим, что `static` позволяет вызывать метод напрямую из класса, не создавая объект этого класса (как `Math.sqrt()`).

- Статический метод может вызывать только другие статические методы.


#### 8. Локальные переменные и их жизнь

Переменные, созданные внутри метода, называются **локальными**.

- Они рождаются в Стике при вызове метода и **умирают**, как только метод закончился.
    
- Переменная из одного метода «не видит» переменную с таким же именем из другого метода.


---

### 💡 Пояснение «от себя» (про «область видимости»):

Самая частая ошибка новичка — попытаться использовать переменную из `main` в другом методе напрямую. Представь, что каждый метод — это отдельная закрытая комната.

- Если тебе нужны данные из другой комнаты, тебе должны их **передать** в руки (через параметры).
    
- Если ты хочешь отдать результат своей работы — ты должен его **выкинуть** в окно (через `return`).
    
- Всё, что ты нарисовал на обоях внутри своей комнаты (локальные переменные), исчезнет, как только ты из неё выйдешь.
